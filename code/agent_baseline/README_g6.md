`Toolbox(..., gate6=True)` 或 `run_session(..., gate6=True)` 同样支持；启用时归档 backends.gate6。

view 保留 image_size，新增 original_size=[width,height] 和原图坐标说明；裁图也返回整幅原图尺寸。
compare_features 保留分数及实例，仅添加 score_quantiles（min/p10/p25/p50/p75/p90/max）；空提议各分位为 null。
