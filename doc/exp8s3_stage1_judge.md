# 任务：实验 8 补充 3，只用补漏组训练补漏判断器

给服务器上的 Claude。前置：`results/exp8s2_judge_by_cell.md`（分流规则、第 1b 步修正、第 2 步判断器按组 AUC），`results/exp8_object_pool.md`（U5 单元、V1 训练设置）。**等 exp8s2 第 1b 步完成后再开始**，分流一律用第 1b 步修正后的规则。

## 目标（Ethan 2026-10-24）
补漏阶段只负责“检测器几乎没画出、精修阶段接收不到”的漏检，核心是 **②（无信号·孤立）**。整体漏检率不再是主指标，相当一部分留给后续 MLLM 精修。本实验要回答：**只用补漏组训练的判断器，能以多低的 F1 代价换回多少 ② 漏检。** F1 可以下降，要看的是“② 召回 vs ΔF1”的整条关系。

## Ethan 的话
“我始终相信 Claude 能把补漏这件事处理好：以尽可能低的 F1 代价，换取较高的第二类漏检召回。”

所以在下面的规则之内，实现细节（例如单元拆分的边界情况、MLP 的学习率、早停耐心、梯度提升树的参数范围）由你自行判断，选一个合理的做法，写明理由即可，不必停下来问。做完规定内容后，如果你看到能让“② 召回 vs ΔF1”曲线明显变好的方向（例如换一种已缓存的特征、换一种损失），可以在预算内加做一组，单独成节、标明是额外尝试，并同样遵守“只用验证选、测试评一次”。

## 规则
- 不跑检测器、SAM3、AnyChange、MLLM；只用已有缓存与 exp8 的 U5 单元和元数据。
- 只训练小模型（MLP、梯度提升树），CPU 或单卡；全部预计不超过 12 GPU 小时，超过先报告。
- 阈值、早停只用验证部分选；测试部分每个冻结点只评一次。整条曲线在测试部分也画，但只作描述。

## 数据
- 数据集：SECOND（训练 / 验证沿用 exp8 第 3 步的划分与交叉拟合检测器，测试用官方权重），SYSU（官方 val 分组后的训练 3,200 / 验证 800，测试 4,000）。
- 单元：exp8 第 1 步冻结的 **U5_x4** 单元。按 exp8s2 第 1b 步的做法分流：单元的新增部分中不碰 D⁺（D 外扩 1 像素）的连通域拆成独立单元，r = 0；其余按单元自身掩码算 r，**R(0.1)** 分流。只保留分到补漏组的单元。
- 特征：与 exp8 第 3 步 V1 相同（SECOND 19 维、SYSU 15 维），不加新特征。
- 标签：新增像素真值占比 ≥ 50% 为正、< 10% 为负，中间不参与训练；像素评估包含全部单元。
- 先报告补漏组训练 / 验证 / 测试的单元数、正例数、正例率，以及正例中 ①、②、③ 各占多少。

## 判断器
| 记号 | 说明 |
|---|---|
| M0 | exp8 第 3 步已冻结的 V1 full（全部候选上训练），只在补漏组上评估，作对照 |
| D | 单元内检测器平均概率，不训练，作对照 |

| M2 | 四层 MLP（512 → 256 → 128 → 64），其余同 M1 |

| M1-25 / M1-50 | 与 M1 相同，但正例随机只留 25% / 50%，负例全留；正例权重按留下的数目重算。M1-25、M1-50、M1 各用 3 个随机种子 |
| O | oracle：按单元新增像素的真实精度排序，作上界 |

## 评估
**主曲线（每个判断器、每个数据集，验证与测试各一张）**：扫阈值，横轴 ΔF1（百分点），纵轴 **② 漏检像素召回**（被补回的 ② 漏检像素 ÷ 全部 ② 漏检像素）。同图另画：
- ① 中分到补漏的部分的召回；
- ② 对象召回（② 目标被最终预测覆盖 ≥ 50% 的比例）；
- 补漏组能达到的 ② 召回上限（全部正例单元并入时）。

**冻结点**：在验证部分选 ΔF1 = −0.3、−0.5、−1、−2 四个阈值，冻结后在测试部分各评一次。报告：测试 ΔF1、ΔIoU、② 像素召回、② 对象召回、① 召回、整体漏检率变化、新增误检像素与新增误检连通域 / 图。

**换算指标**：每个冻结点报“每补回 1 个百分点 ② 漏检像素，F1 下降多少”，便于不同判断器直接比较代价。

**正例数量**：M1-25、M1-50、M1 的曲线画在一起（3 个种子取均值，阴影为范围），并报验证 AUC / AP。

**排序指标**：每个判断器在补漏组上的 AUC、AP（2000 次按图整群自助法 95% CI），以及只看 ② 正例 vs 补漏负例的 AUC、AP。

## 判断问题
1. 只用补漏组训练（M1）比 M0 在“② 召回 vs ΔF1”曲线上好多少？例如 ΔF1 = −0.5 时 ② 召回分别是多少？
2. ΔF1 = −0.3 / −0.5 / −1 / −2 时，测试部分 ② 能补回多少？验证到测试是否守得住（SECOND、SYSU 分开说）？
3. 正例从 25% → 50% → 100%，曲线是否还在明显变好？据此人造正例是否值得做？
4. M2、M3 是否比 M1 好？模型容量是不是瓶颈？
5. 与 oracle 的差距有多大？在补漏组里，要达到 ② 召回 50% 需要多高的判断精度？
