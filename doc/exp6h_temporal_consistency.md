# 任务：实验 6h（补充），时相约束辅助损失能否让验证器更好地区分真假变化

给服务器上的 Claude。这是一个小的补充实验，目标是**快速验证**，不追求最终结果。前置结果见 `results/exp6b_verifier.md`、`interim/exp6/tables_6b_6e.md`；如果 6f 已有结果，也读 `results/exp6f_v1_variants.md`。沿用 6b 的训练池、验证集划分（297 张）和评估口径。**不影响正在训练的 V2 和 6f，GPU 紧张时它们优先。**

## 为什么做
- 来源：SAM-CD（Ding 等，TGRS 2024，arXiv 2309.01429）的时相约束损失 L_t = (1 − cos(l1, l2)) · [未变化]，只在未变化像素上把两期表示拉近，和变化 BCE 等权相加。它在 LEVIR 上带来 +0.5 F1（94.98 → 95.50），没在 SECOND 上验证过。
- 对我们的意义：exp4/5 里零样本的"两期语义一致性"信号不够用（RemoteCLIP 两期相似度 AUC 0.51–0.67），6b 里冻结骨干特征反而不如无骨干基线。假设是：两期特征差里混着色调、季节、成像差异。L_t 用训练数据告诉模型"这种程度的差异不算变化"，可能让 |z1 − z2| 更干净。
- 注意：L_t 只拉近、不推开，单独使用会退化成"全图都一样"。必须和主分类损失一起训。

## 规则（同 6f）
- 所有取舍（λ、结构、早停、阈值）只看验证集；测试集只在每个变体最终确定后评估一次。
- 不重训检测器；不用测试集数据训练或调参；不用真值语义图生成候选或特征。L_t 用到的"未变化"只来自 train 的真值变化掩码和 6a 的切块标签。
- 6h-1 预计在 2 GPU 小时内完成；超过 4 GPU 小时先停下报告。6h-2 的预算跟 6f-C 一致。

## 6h-1：在 6b 的切块特征上加投影头 + L_t（先做，最便宜）
- 特征：6b 中验证 AP 最好的骨干（6b 为 dinov3）在切块掩码内池化后的两期特征 f1、f2。**先检查 6b 是否缓存了这些特征**；有就直接用，没有就按 6b 的方式重提一次，并记录耗时。
- 结构：共享投影头 g（2 层 MLP，输出 64 维，LayerNorm）得到 z1 = g(f1)、z2 = g(f2)；分类器输入 [z1, z2, |z1 − z2|, cos(z1, z2), 6b none 版本的元数据特征（检测器概率统计、面积、来源；若 6f-A1 有效则用图内排名版本）]，输出 P(真变化)。
- 损失：L = BCE（同 6b 的加权方式） + λ · mean_{负样本切块}[1 − cos(z1, z2)]。负样本即 6a 规则中真值变化占比 < 10% 的切块。
- 变体：
  1. **G1-0**：λ = 0，其余完全相同（对照，必须做；它和 6b 的差别只在投影头结构）。
  2. **G1-cos**：λ ∈ {0.1, 0.3, 1.0}，在验证集上选。
  3. **G1-sm**（贴近 SAM-CD 原式）：投影头输出 8 维，先做温度 T = 3 的 softmax 再算余弦，λ 同样在 {0.1, 0.3, 1.0} 中选。
- 诊断（必须做）：只用 cos(z1, z2) 一个数当分数，报告验证集和测试集 AUC，对照 G1-0 的 cos、原始骨干特征的 cos(f1, f2)，以及 exp5 的 RemoteCLIP 两期相似度。这一项直接回答"L_t 有没有把两期相似度练成可用的信号"。
- 每个设置跑 3 个随机种子，报告均值和标准差。6b 中验证 AUC 的差异多在 0.01 量级，单种子不足以下结论。

## 6h-2：挂在 6f-C 原分辨率小网络上（6f-C 有结果后再做）
- 只有 6f-C 已经跑出基线时才做；6f-C 未开跑或被停下，就跳过本节并写明。
- 做法：沿用 6f-C 的输入、结构、训练设置不变，只加 L_t。在小 CNN 的最后一层空间特征图（不是池化后的向量）上，对裁块内**真值未变化像素**计算两期特征的 1 − cos，取平均乘 λ 加到主损失上。像素级掩码从 train 真值变化图按同样的裁剪和缩放得到。λ ∈ {0.1, 0.3, 1.0}，验证集选。
- 对照：6f-C 原版（λ = 0），同样 3 个种子。

## 评估（每个变体都做，同 6b / 6f 口径）
1. 验证集与测试集：AUC、AP、召回 80% / 90% 时的误检率、召回 80% 时补入像素精度，与 F1/2 门槛对照（验证 35.7%，测试 37.08%）。
2. 端到端：验证集选阈值（若 6f-A2 的每图预算有效，同时报告预算版本），测试集评估一次，报告 F1、P、R、ΔF1、新增 TP / FP 像素、目标级召回（按面积分桶）。来源组合只做"全部"即可。
3. 召回优先口径：新增 FP 预算 5%、10%、20% 时的目标级召回（同 6f）。
4. 训练曲线：每个变体的训练 / 验证 AUC 随轮次的曲线，看 L_t 是否减轻了 6b 中"第 1–7 轮就过拟合"的现象。

## 判断问题（写进 summary）
1. 同样的特征和结构下，加 L_t 是否稳定提高验证 AUC / AP（超过种子间标准差）？最好的 λ 是多少？
2. 加 L_t 后，单用 cos(z1, z2) 当分数的 AUC 能到多少？是否明显超过原始特征余弦和 RemoteCLIP（0.51–0.67）？
3. 测试集上 ΔF1 和召回优先口径是否随之改善？是否超过无骨干基线（AUC 0.874）？
4. 6h-2（如果做了）：在原分辨率小网络上，L_t 的效果和 6h-1 是否一致？

## 优先级
6h-1 的特征检查 → G1-0 → G1-cos → 诊断 → G1-sm → 6h-2。
