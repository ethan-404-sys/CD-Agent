# 任务：统一评价指标（从现在起所有实验都按此报告）

给服务器上的 Claude。到目前为止，端到端结果几乎只看像素 F1（加少量目标级召回）。问题是像素 F1 对掩码形状不敏感：oracle 补漏把 SLIC 切块整块并入，边缘呈 17 像素左右的台阶状（见 `results/pipeline_figs/test_987/final_mask.jpg`），像素 F1 仍然大涨。只看像素 F1，会让方法朝"多盖像素、不管形状"的方向过拟合。本文档定义一套固定指标，并要求对已有关键结果补算。**只做评估，不训练任何模型。**

## 指标集（二值变化图，变化类为正类）
实现放 `code/probe/metrics_cd.py`，一个函数输入（预测二值图，真值二值图），输出下面全部指标；数据集级一律按全部像素或全部目标汇总（micro），另给逐图分布。

**A. 像素级**（保留）
- F1、精度、召回、**变化类 IoU**。

**B. 边界级**（新增，衡量边缘是否贴合）
- **Boundary F1**（BF score）：分别提取预测和真值的边界像素，容差 d 像素内匹配，算边界精度、召回、F1。报告 d = 2 和 d = 5。
- **Boundary IoU**（Cheng et al., CVPR 2021）：只在距各自轮廓 d 像素以内的带状区域计算 IoU，d 取图像对角线的 2%（512² 约 14 像素），同时报告 d = 3。
- 写明边界提取方式（例如掩码减去其 3×3 腐蚀）。

**C. 目标级**（新增或统一口径）
- 真值目标 = 真值变化图的 8 连通域；预测目标 = 预测图的 8 连通域。
- **目标召回**：真值目标被预测覆盖 ≥ 50% 的比例；**目标精度**：预测目标中与真值重叠 ≥ 50% 的比例；**目标 F1**。
- 按真值目标面积分桶（< 100、100–1,000、1,000–5,000、> 5,000 像素）报告目标召回。
- **每图新增误检目标数**：校正后比校正前多出来的、与真值不重叠的连通域个数（均值和 90% 分位）。

**D. 形状质量**（新增，专门抓"锯齿"）
- **边界粗糙度**：预测掩码周长 ÷ 其凸包周长（或经高斯平滑后掩码的周长），与真值的同一指标对比。比真值高得多，说明边缘锯齿。
- **碎片数**：每图预测连通域个数，及面积 < 20 像素的碎片个数。

**E. 逐图分布**（新增，防止平均数掩盖损害）
- 每张图的 ΔF1：提升图占比、下降图占比、ΔF1 的 10% / 50% / 90% 分位数、最差 5 张图及其 ΔF1。

## 需要补算的已有结果
在 SECOND test（必要时 SYSU test）上，对下面每一行算全套指标，汇总成一张表：
1. 检测器原始预测（MambaSCD-Base，0.5 阈值）；
2. 切块级 oracle 补漏（B+G0.05、B+G0.05+H1）；
3. 切块级 oracle 去误检；
4. 两路都做（oracle）；
5. V1 无骨干，B+G0.05+H1，验证集阈值 0.820（6b 主结果）；
6. 6f 中测试集最好的设定（如有）。

对 2–4，另加两个**只改边缘、不改取舍**的变体，看能否保住像素 F1 同时改善 B、D 两组指标：
- **2a / 4a 检测器软边界**：已确认并入的切块内，只保留检测器概率 > 0.05 的像素，再与切块外扩 2 像素取交；
- **2b / 4b 形态学平滑**：对最终图做半径 2 的开运算加闭运算。
- **2c / 4c SAM 小框精修**：对每个已确认并入的切块（相邻切块先合并成连通域），用其紧外接框加内部离边界最远的 1 个正点提示 SAM3（裁块方式同实验 2），SAM 掩码与该连通域外扩 5 像素的范围取交集后替换原切块。去误检一侧不做。另报告 SAM 掩码与真值的 IoU，按面积分桶。

输出 `results/eval_metrics.md`（全表 + 每组指标的一句话解读）和 `figures/eval_metrics/`（test_987 上 1、4、4a、4b、4c 的掩码并排图，边界叠加在 t2 上）。
