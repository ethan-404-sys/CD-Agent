# 开放词汇变化检测 Agent：任务定义与方法设计 v0

日期：2026-10-28。依据：`results/survey_ovcd.md`（文献调研），以及本仓库 exp6j、exp6l、exp8s7、`results/miss_share.md` 的结论。流程图见 `doc/ovcd_agent_v0_pipeline.html`。

本文是 v0：先把任务、评测和最简单的完整流程定下来，效果问题放到流程跑通之后逐个模块改进。

## 1. 为什么换成这个故事

**旧故事的问题**：接在任意检测器后面补漏、修掩码，本质是一个后处理算法。审稿人会问：既然你的模块也要在每个数据集上训练，为什么不直接训一个更强的检测器？

**新故事**：给定两期影像和一个类别文本，MLLM 驱动的 Agent 通过“提出、核实、修正”的多轮循环，得到这个类别的变化掩码。

**它能回答审稿人的原因**：开放词汇的前提是用户可以问任意类别，而这个类别没有标注数据，没法为它单独训练检测器。于是“不针对类别训练、靠通用知识核实和修正”就有了存在的理由。

**这个前提反过来约束我们**：方法里的模块必须免训练，或者只训练一次、与类别无关，并且训练数据不含任何评测数据集。按每个数据集各训一个的模块（exp8s7 的融合判断器、exp6m 的分数据集微调）只能作为分析或上限参照，不能当方法本身。

**文献里的空白**（调研第 6 节）：
- 没有找到用 MLLM 多轮迭代修改变化掩码的工作。最接近的是一次性输出掩码的 MLLM（UniChange、Delta-LLaVA），和单图多轮分割 Agent（SegAgent、SAM-Veteran）。
- 免训练 OVCD 的主要误差，正好是 Agent 要处理的三类问题：
  - 伪变化：配准错位造成的边界响应、换色、季节；
  - 整目标漏检：I-M-C 识别阶段丢掉的目标、背景型类别、小目标；
  - 标注口径：同类内变化在 OR 规则下算正样本，但基于语义差异的方法在结构上检测不到。
- 现有 OVCD 论文都只报像素指标，没有目标级的整目标漏检率和误检率。

## 2. 任务定义

| 项 | 定义 |
|---|---|
| 输入 | 两期影像 I1、I2，类别文本 c（如 building） |
| 输出 | 类别 c 的二值变化掩码 |
| 真值 | 沿用 DynamicEarth 评测代码的 **OR 规则**：变化像素中，t1 或 t2 属于 c 即为正样本。建筑数据集直接用二值标签 |
| 类别文本 | 每个类别一份固定、公开的同义词表；背景提示固定为 background 加其余类别名。不按数据集调提示 |
| 训练 | v0 全部模块免训练 |
| 超参数与阈值 | 只在验证部分选，测试只评一次。见第 9 节待定事项 1 |

**方向分项**：SECOND 有两期语义标签，可以把每个类别的正样本拆成三项分别报告召回：
- 出现：t2 = c，t1 ≠ c；
- 消失：t1 = c，t2 ≠ c；
- 同类内变化：t1 = t2 = c，如建筑拆除重建。

这样能直接量出基于语义差异的方法在同类内变化上的盲区，也能换算成指代变化检测“只算新增”的口径。

## 4. 评测

- **主指标**：变化类 F1^c，在整个测试集上累计 TP、FP、FN。同时报告 IoU^c、Precision、Recall。SECOND 报六类宏平均和逐类数值。
- **目标级指标**：
  - 整目标漏检率：真值连通域与预测的 IoU < 0.1 的比例，对应补漏；
  - 整目标误检率：预测连通域与真值的 IoU < 0.1 的比例，对应去误检。
- **辅助指标**：逐图平均 F1。调研显示，累计 F1 与逐图平均 F1 可能相差 30 个点。
- **方向分项**：SECOND 的出现、消失、同类内变化三项召回。
- **成本**：每对影像的 MLLM 调用次数、推理时间；预算曲线，即“每图最多 k 次调用”下的 F1。

## 6. 方法：Agent v0

### 6.1 总体结构

```
输入 (I1, I2, c)
  → 第 1 步  口径卡：把 c 展开成“什么算变化、什么不算”
  → 第 2 步  初始化：免训练 OVCD 方法给出初始掩码 M0
  → 第 3 步  建立状态：连通域清单 + 待查队列
  → 第 4 步  Agent 循环（三个阶段，每步：观察 → 选动作 → 调工具 → 更新掩码）
       阶段 A  核实已有连通域，去误检
       阶段 B  查看可疑区域，补漏检
       阶段 C  修边界
  → 第 5 步  停止：预算用完或队列为空
输出 M_final，以及每一步的轨迹记录
```

### 6.2 各步说明

**第 1 步：口径卡。** 每个类别一张固定的卡片，写明在 OR 规则下什么算变化、什么不算。例如 building：
- 算：新建、拆除、拆除后重建；
- 不算：阴影、季节色调、配准错位造成的边缘响应、车辆和临时堆放。

口径卡写进系统提示，并在核实时逐条引用。它把我们 exp6k、exp6l 里反复遇到的伪变化问题，变成方法里明确的一部分。

**第 2 步：初始化。** 默认用 DynamicEarth M-C-I。另外用 ReA-OVCD 做第二种初始化，检验方法是否与前端互补。初始化方法如果输出分数图，就一并保存，供第 4 步找可疑区域用。

**第 3 步：建立状态。** 状态包括：
- 当前掩码 M_t；
- 连通域清单：每个连通域的编号、面积、外接框、初始化给的分数；
- 待查队列：阶段 A 的连通域按“可疑程度”排序，阶段 B 的可疑区域按来源分数排序；
- 已用预算。

**第 4 步：Agent 循环。** 动作和工具：

| 编号 | 动作 | 工具 | 说明 |
|---|---|---|---|
| T1 | 看全局 | 渲染全图缩略图，标出连通域编号 | 让 MLLM 知道整体情况 |
| T2 | 放大 | 裁剪区域，输出 T1、T2 近景和当前掩码叠加图 | 解决整图分辨率不够的问题 |
| T3 | 核实 | MLLM 回答“这里是否有 c 的变化”，给出是否、伪变化类型和理由 | 引用口径卡 |
| T4 | 删除 | 从掩码里去掉一个连通域 | 阶段 A |
| T5 | 新增 | MLLM 在放大区域里画框，SAM 把框变成掩码，按 OR 规则在两期上各分一次取并集 | 阶段 B；MLLM 只在局部画框，不从零画整图 |
| T6 | 精修 | 用框或点提示 SAM 重新分割一个连通域，替换原掩码 | 阶段 C |
| T7 | 找可疑区域 | 按类别生成待查清单：初始化分数图里接近阈值的区域、SAM3 按类别文本两期分割的差异、AnyChange 提议中属于 c 的部分 | 阶段 B 的入口；复用之前补漏候选的经验，但改成按类别生成 |
| T8 | 结束 | — | — |

**v0 的循环由程序编排**：程序按阶段 A → B → C 的顺序，把待查项一个个交给 MLLM，MLLM 只做 T3 和 T5 的判断与画框，删除、新增、精修由程序根据它的回答执行。

**v1 再让 MLLM 自己选动作**：它看完全局后，自己决定下一步放大哪里、做什么、何时结束。调研里单图分割 Agent 的经验是：停止时机需要专门处理，只奖励最终结果会产生冗余动作，首步定位是主要瓶颈。先用编排式把整个流程跑通，再换自主式，两者的差就是“自主决策”的价值。

**第 5 步：停止与预算。** 每张图设调用上限 k（如 10、20、50），评测时画“k 对 F1”的预算曲线。每一步写入轨迹记录，包括动作、输入图、MLLM 回答、掩码变化和 ΔF1，供审核前端的轨迹视图使用。

## 7. 实验计划

| 里程碑 | 内容 | 判断标准 |
|---|---|---|
| M0 复现 | DynamicEarth 两个配置、ReA-OVCD，在 LEVIR、SECOND（593 与 1,694 两种划分）、WHU 上重跑 | 与原文数字差在 2 个点以内；差得多就查原因，记录 |
| M1 错误分析 | 在初始化输出上统计：整目标漏检率、整目标误检率、误检与漏检的像素占比、SECOND 方向分项 | 决定阶段 A（去误检）和阶段 B（补漏）的预算分配 |
| M2 可行性 | 只做阶段 A：MLLM 核实每个初始连通域，判否就删 | **关键的去留判断**：免训练 MLLM 能否稳定提升 F1^c。不能就先停下讨论 |
| M3 补漏 | 加入阶段 B：T7 找可疑区域 + T5 新增 | 整目标漏检率下降，F1^c 不降 |
| M4 精修 | 加入阶段 C | 边界指标与 F1^c |
| M5 自主 | MLLM 自己选动作 | 相对编排式的提升与调用次数 |
| M6 消融 | 逐个去掉动作；换初始化方法；换 MLLM；去掉口径卡 | 各部分的贡献 |

## 8. 风险

1. **MLLM 核实能力弱。** exp6j、exp6l 里，免训练 MLLM 逐个判断补漏候选不如检测器分数；调研里 TriSV-CD 也报告 VLM 判断伪变化不稳定，换一种提示措辞，一致率只有 62.78%。M2 就是为了尽早检验这一点。和之前不同的是，这次判断的是初始化方法给出的完整连通域，而不是零碎的补漏残块，难度可能更低。
2. **OR 规则与伪变化冲突。** SECOND 把同类内变化算正样本，比如屋顶换色在 SECOND 里可能算变化，口径卡里“换色不算”就会和真值冲突。口径卡要按 OR 规则写，并用方向分项单独看同类内变化。
3. **提示敏感。** 调研显示 OVCD 普遍对提示词敏感。同义词表和口径卡在 v0 定下后就固定，消融里单独评。
4. **划分与复现不一致。** 各论文的划分和复现数字最多差 8 个点。主表只用我们自己重跑的数字。
5. **成本。** SECOND 一张图的变化很多，调用次数可能很大。预算曲线必须报。
