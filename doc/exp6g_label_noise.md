# 任务：实验 6g，SECOND 标签噪声排查

给服务器上的 Claude。前置结果见 `results/exp5b_confirm.md` 的判错样例、`results/exp6a_pool.md`、`results/exp6b_verifier.md`。本任务**不训练任何模型**，只抽样、出标注页面、统计。生成页面是 CPU 工作，可以和 V2 并行；V2 的评估优先。

## 为什么做
1. **判错样例里有标注不一致**：`results/exp5b_error_examples/second/` 中，test_1147 屋顶由灰翻新成蓝，真值为"未变化"；test_193 屋顶由灰变红，真值为"变化（改建）"。同一类变化，标法相反。另有 10–50 像素、t1 很模糊的切块，人眼无法判断，真值却给了确定标签（如 test_1243，10 像素，标"变化"）。
2. **V1 无骨干基线停在 AUC 0.86–0.87**，训练曲线与验证曲线重合，像是碰到天花板。标签噪声是可能原因之一。
3. 如果噪声大，影响两头：验证器学到的标签有错；**评估也会低估我们的方法**，即补进来的"假变化"里可能有一部分是没标的真变化。

判错样例是挑出来的，会高估噪声，所以需要按分层随机抽样估计真实比例。

## 规则
- 不修改任何官方真值文件。人工审核结果单独存放。
- 标注时**不显示**真值、来源、分数和所属分层（盲审）。
- 不调用外部 API。如做 MLLM 辅助审核（第 4 步，可选），只用本地模型。

## 第 1 步：分层抽样（共约 320 个切块）
从 6a/6b 已有的切块池中抽取，切块定义、标签规则同 6a（真值占比 ≥ 50% 为正，< 10% 为负）。V1 分数用 6b 的 none 版本。

| 分层 | 来源 | 数量 | 目的 |
|---|---|---:|---|
| S1 随机正例 | test 池，按来源分层 | 60 | 正例标签的错误率 |
| S2 随机负例 | test 池，按来源分层 | 60 | 负例标签的错误率 |
| S3 高分负例 | test 池，V1 分数最高的负例中随机抽 | 60 | 我们补进来的"假变化"里有多少其实是真变化 |
| S4 低分正例 | test 池，V1 分数最低的正例中随机抽 | 40 | 真值说变了、模型说没变的，哪边对 |
| S5 难类正例 | test 池，改建（建筑→建筑）与植被互变的正例 | 40 | 难类的标注一致性 |
| S6 训练池随机 | second_cv 池，正负各 20 | 40 | 训练标签与测试标签的噪声是否相近 |
| 重复样本 | 从上面随机复制 20 个，打乱插入 | 20 | 标注人自身的一致性 |

S3 的"高分"用 6b 中 B+G0.05+H1 组合下验证集选定的阈值（0.820）以上。另记录每个样本的面积，用于后面按面积拆分。

## 第 2 步：标注页面
生成一个**自包含的本地 HTML**：`audit/label_audit.html`，图片内联（base64）或放在同目录 `audit/crops/`，浏览器直接打开即可，不依赖外网。
- 每个样本并排显示 t1、t2 两张裁块，裁法同 V2（以切块为中心，放大到 384×384），用细轮廓线圈出切块；可切换显示一张更大范围的上下文图（切块外接框外扩 3 倍）。
- 四个按钮：**变了 / 没变 / 看不清 / 跳过**，支持键盘快捷键（1/2/3/0），可返回上一个修改。
- 进度条；结果存 `localStorage`，可随时关闭继续；提供"导出结果"按钮，下载 `audit_answers.json`（样本 id → 选项、时间戳）。
- 样本顺序随机打乱，分层信息只存在 `audit/samples.json`，页面上不显示。
- 把页面和 crops 推到仓库，告诉用户打开方式。用户标完后会把 `audit_answers.json` 放回 `audit/`。

## 第 3 步：统计（用户标注完成后）
- 每个分层：人工判断与真值不一致的比例，附 Wilson 95% 置信区间；"看不清"单独计数，不算错。
- 按面积分桶（< 50、50–300、300–1000、> 1000 像素）的不一致率和"看不清"比例。
- 按分层权重估计 test 池和训练池整体的标签错误率。
- 重复样本的自一致率。
- **修正后的精度估计**：用 S3 的结果估计 V1 补入像素中"真值说假、实际为真"的比例，重新估计召回 80% 时补入像素精度（6b 为 21.3%），与 F1/2 门槛 37.08% 对照，并说明置信区间。
- 列出 10 个最典型的标注错误样例（图 + 一句说明）。

## 第 4 步（可选）：MLLM 辅助审核
如果人工结果显示噪声明显（任一分层不一致率 > 20%），用本地 Qwen 模型（不微调，同 V2 的输入格式）对同一批样本作答，计算与人工判断的一致率。一致率高的话，可考虑用它扩大审核规模；一致率低就不做。

## 判断问题（写进结果文件）
1. SECOND 的切块标签整体错误率大约多少？哪类变化、哪个面积段最严重？
2. V1 补进来的"假变化"里，有多少其实是真变化？修正后补入像素精度离 37% 门槛还有多远？
3. 训练池和测试池的噪声是否相近？
4. 据此，下一步应该：（a）忽略噪声，继续 V2/6f；（b）在干净子集上补充评估；（c）训练时排除看不清的小切块或用抗噪损失。给出建议和理由。
