## 目的（Ethan 2026-10-28）
- 这一页**不是审核**：没有通过、剔除按钮，也不写任何判定。
- 它的用途是让 Ethan 熟悉 exp8s7 版本的漏检候选是怎么一步步产生的。
- 要求逻辑清楚、一步一图。可以用叠加、透明度、前后对比滑块、逐步播放动画，怎么方便人理解怎么来。

## 入口：模式切换
- 前端顶部加模式切换，至少两个：
  - “MLLM 判断器审核”：现有功能，保持不变；
  - “漏检候选审核”：本任务。
- 两种模式可以随时切换。用 URL 区分模式，刷新后停在当前模式。

## 全局控件
- **数据集下拉**：SECOND、SYSU 必做。LEVIR、WHU 有现成缓存的话也加上，用各自冻结的单元与过滤。
- **划分**：验证、测试。
- **选图**：
  - 每个数据集预选约 5 张“典型图”，要求每一步都有看得见的例子，尤其要有 ②；
  - 另外支持按图名搜索和随机一张。
- 每一步右侧显示本步的参数、这张图在这一步的数量，以及整个数据集的平均数量。
- 页面顶部用一条漏斗显示这张图从第 0 步到第 6 步，候选个数和 ② 覆盖是怎么变化的。

## 步骤

### 第 0 步：原始数据
- 并排显示 T1、T2、GT、检测器结果。检测器结果给二值掩码和概率热力图两种，可切换。
- 可选图层：在 GT 上按 ①②③⑤ 着色，显示漏检的分类。默认关闭，第 4 步再打开。

### 第 1 步：各来源初始化候选
- **来源下拉**：SECOND 有 B、G0.05、H1；SYSU、LEVIR、WHU 有 B、G0.05。
- **一次只显示一个来源**，不要一开始就叠在一起。每个来源配一句话说明它是怎么来的：
  - B：两期语义类别不同的区域；
  - G0.05：检测器概率在 0.05 到 0.5 之间的连通区域；
  - H1：AnyChange，SAM 物体的两期特征差异。
- 叠加在 T2 上显示该来源的候选轮廓，并显示候选数和它单独能覆盖的 ② 目标比例。
- 最后可以选“全部叠加”，各来源用不同颜色。这只是一个选项，不是默认视图。

### 第 2 步：去重
- 自动挑一块典型区域裁剪放大：几个来源的候选在这里高度重叠，并且发生了合并。
- 先显示合并前：多种颜色的轮廓重叠。
- 再显示合并后：一个对象。
- 用前后滑块或播放动画衔接。写明合并规则：IoU ≥ 0.5，或交集 / 较小面积 ≥ 0.8，直接对合并。

### 第 3 步：切块（U5）与新增像素
1. 裁剪一个超过面积阈值的大对象，显示它被 SAM 自动掩码切成的小块。写明阈值：SECOND 1,088 像素，SYSU 4,056 像素。
2. 在同一裁剪区域，先叠检测器掩码，再叠候选块，最后只留下“候选减去检测器已报部分”的新增像素。三张图依次播放或用滑块切换。
3. 同时给一个没被切的普通对象作对照。

### 第 4 步：分流
- 打开 GT 的 ①②③ 着色，用真实例子说明，不能只写一句规则：
  - **① 无信号、贴着检测结果**：漏检紧挨检测器已报区域；
  - **② 无信号、孤立**：1 像素膨胀后也碰不到检测结果。画出膨胀环帮助理解；
  - **③ 有信号**：检测器有响应但没过阈值。
  - 每类至少一个裁剪示例，同时显示 GT、检测器结果和候选。
- 再显示 1d 分流：每个示例标出 r（候选内检测器已报部分的占比），并说明落在补漏组（r < 0.1）还是精修组。补漏组和精修组各至少一个例子。
- 说明 ①②③ 是用 GT 定义的评估分类，实际流程里看不到；实际流程只用 r 分流。

### 第 5 步：碎片过滤
- 显示该数据集的冻结过滤：SECOND F3A200（内切半径 ≥ 2，新增 ≥ 200 像素），SYSU F2（3×3 开运算，新增 ≥ 100 像素）。
- 给典型例子：
  - 被去掉的细条；
  - 被去掉的小块；
  - 保留下来的块，最好有一个是 ②。
- 每个例子显示过滤前后，并标出关键数值：面积、内切半径。

### 第 6 步：最终候选
- 整图显示最终的补漏候选，可按是否为 ② 着色（GT 视角）。
- 点任意一个候选，旁边放大裁剪，显示 T1、T2 和新增像素。
- 列出这张图的最终候选数，以及覆盖了几个 ② 目标、漏了几个。漏掉的 ② 用虚线标出，说明它们不在任何候选里。

## 实现要求
- 图都离线预渲染成 PNG，数值存 JSON，前端只负责读取和切换，不在线跑分割或过滤。
- 典型区域和典型图由脚本按规则自动挑选，规则写在 README 里，可复现。
- 颜色约定全页统一，图例常驻：
  - 检测器：蓝色；
  - 候选：黄色；
  - 新增像素：绿色；
  - GT 的 ①②③：三种区分明显的颜色。
- 不改动现有审核功能和数据库表。
