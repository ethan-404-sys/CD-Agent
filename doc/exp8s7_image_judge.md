# 任务：实验 8 补充 7，在过滤后的补漏组上训练用图像信息的判断器

给服务器上的 Claude。前置：`results/exp8s6_filter_coverage.md`（冻结的碎片过滤）、`results/exp8s5_checks_budget.md`（预算曲线）、`results/exp8s3_stage1_judge.md`（M1-ign3、D）、`results/exp6b_verifier.md` 与 `results/exp6f_v1_variants.md`（以前的图像特征判断器）、`doc/exp6j_rs_mllm_zero_shot.md`（遥感 MLLM 零样本，同一批样本）。

## 为什么做
- 以前用图像特征（SAM / DINOv3 / RemoteCLIP、CNN、千问 V2）的判断器都没赢过只用元数据的 V1（0.82–0.84 对 0.875）。但那是在**全部候选**上比的，大量候选落在检测器已画区域，检测器概率本来就准。
- 现在的问题不同：
  - 补漏组是检测器几乎没信号的地方，元数据在 ② 上只有 AUC 约 0.7、AP 约 0.08，与直接用检测器均值 D 相同。
  - exp8s6 过滤后只剩较大的单元，图像信息不再被细条碎片拖累。
  - “补漏组 + 过滤后 + 图像信息”这个组合从没测过。
- 在合并方案里（补漏、去误检、精修都交给 MLLM），判断器的角色是**给 MLLM 排待查清单**：排得越准，MLLM 要看的候选越少。

## 必守的规则
- **数据**：exp8 的 U5_x4 单元，1d 冻结分流规则只取补漏组，再套 exp8s6 冻结的过滤（SECOND：去细条 + 新增 ≥ 200 像素；SYSU：开运算 + 新增 ≥ 100 像素），训练、验证、测试同样处理。判断对象是单元的新增像素（单元 \ D）。划分沿用 exp8s3：SECOND 训练 2671 / 验证 297（交叉拟合检测器）/ 测试 1694（官方检测器）；SYSU 训练 3200 / 验证 800 / 测试 4000。
- **标签**：同 exp8s3，新增像素真值占比 ≥ 50% 为正、< 10% 为负、中间不参与训练。是否沿用 M1-ign3 的“忽略 ③ 为主的正例”由你决定，写明理由。
- **选择与评估**：所有模型选择、超参数、早停、阈值只用验证部分；测试部分只在最后对冻结的模型评一次。迭代过程中不看测试结果。
- **不准**：用真值生成输入；用测试集调任何东西；调用外部 API；跑 SAM3、AnyChange 重新生成候选。
- **预算**：总计不超过 24 GPU 小时。预计超过时先停下报告。

## 必须包含的对照
无论你最后用什么方法，下面几组都要在同一数据、同一评估下报告：
1. D：单元内检测器均值，不训练；
2. M1-ign3：exp8s3 已训练的元数据判断器，直接打分；
3. 只用元数据，在过滤后的数据上重训（同 M1-ign3 结构）；
4. 只用图像信息（你的最好方案去掉元数据）；
5. 图像 + 元数据（你的最好方案）；
6. oracle：按新增像素真实精度排序，作上界。

## 评估
- **主指标**（验证、测试，SECOND、SYSU 分开）：
  - “② 正例 vs 补漏负例”的 AUC、AP（2000 次按图整群自助法 95% CI）；
  - 预算曲线：每图前 k 个（k = 1、2、3、5、10、20、全部）的 ② 对象召回上限，口径同 exp8s5。
- **辅助**：全部正例 vs 负例的 AUC / AP；“② 正例 vs 难负例”（检测器均值最高 20% 的负例）的 AUC / AP；冻结点（验证选 ΔF1 = −0.5、−1、−2 的阈值）在测试上的 ΔF1、② 对象召回与新增误检连通域 / 图。
- **与 exp6j 对齐**：在 exp6j 第 2 步抽到的同一批单元上，也报告你的判断器的 AUC / AP，便于和遥感 MLLM 零样本直接比较（若 exp6j 尚未完成，记下样本清单，补跑即可）。
- **错误分析**：从验证部分各抽 12 个“你的判断器判对、D 判错”和“你的判断器判错、D 判对”的单元，出并排图（T1、T2、上下文、热力图），每张一句说明，归为：认错地物 / 季节或色调 / 配准错位 / 真值可疑 / 太小看不清 / 其他。

## 判断问题
1. 在过滤后的补漏组上，图像信息能否明显超过元数据？例如 ② AP 能否从约 0.08 提到 0.15 以上？
2. 图像 + 元数据比单独哪个好多少？
3. 用你的判断器排序，每图前 10 个、20 个能盖住多少 ②？相对 M1-ign3 和 oracle 各差多少？
4. 和 exp6j 最好的遥感 MLLM 零样本相比如何？
5. 主要还错在哪类样本？下一步最值得做什么？
