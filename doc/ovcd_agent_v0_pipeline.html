OVCD Agent v0 流程

给定两期影像和一个类别文本，MLLM 驱动的 Agent 通过“提出、核实、修正”的多轮循环，得到这个类别的变化掩码。v0 全部模块免训练，循环由程序编排。

程序执行 MLLM 判断 掩码输入输出 评测 去留判断

主流程

  1. 0

    输入

    数据

    两期影像 I1、I2，以及一个类别文本 c，例如 building、low vegetation。

    真值：OR 规则，变化像素中 t1 或 t2 属于 c 即为正数据：LEVIR、WHU、SECOND 六类
  2. 1

    口径卡

    程序每类一张，固定不调

    把类别 c 展开成“什么算变化、什么不算”，写进系统提示，核实时逐条引用。

    • building 算：新建、拆除、拆除后重建
    • building 不算：阴影、季节色调、配准错位的边缘响应、车辆和临时堆放
    • 附一份固定的同义词表，背景提示为 background 加其余类别名
  3. 2

    初始化

    程序输出 M0

    用免训练的 OVCD 方法给出初始掩码 M0；有分数图就一并保存，供第 4 步找可疑区域。

    默认：DynamicEarth M-C-I第二种：ReA-OVCD，检验与强前端是否互补
  4. 3

    建立状态

    程序
    • 当前掩码 Mt
    • 连通域清单：编号、面积、外接框、初始化分数
    • 待查队列：阶段 A 按可疑程度排连通域；阶段 B 按来源分数排可疑区域
    • 已用预算
  5. 4

    Agent 循环

    MLLM 判断程序执行

    按阶段 A → B → C 依次处理待查队列。每个待查项走一遍下面的五步。

    单步循环 重复直到预算用完或队列为空
    4.1 程序取下一个待查项
    4.2 程序 · T2放大，渲染 T1、T2 近景和掩码叠加
    4.3 MLLM · T3/T5按口径卡核实，或在局部画框
    4.4 程序 · T4/T5/T6删除、新增或精修，更新 Mt
    4.5 程序记录轨迹：动作、回答、掩码变化
    ↺ 回到 4.1

    阶段 A 去误检

    对 M0 的每个连通域：MLLM 核实是否为 c 的变化，判否则删除。
    待查项：初始连通域　工具：T3 → T4

    阶段 B 补漏检

    对可疑区域：MLLM 核实并在放大图里画框，SAM 在两期各分一次取并集后加入。
    待查项：T7 的可疑区域　工具：T7 → T3 → T5

    阶段 C 修边界

    对保留下来的连通域：用框或点提示 SAM 重新分割，替换原掩码。
    待查项：保留的连通域　工具：T6
  6. 5

    停止与输出

    输出 M_final评测

    每张图设调用上限 k（10、20、50），用完或队列为空即停止。输出最终掩码和完整轨迹，轨迹供审核前端回放。

    主指标：F1c，累计 TP、FP、FN另报：IoUc、P、R、整目标漏检率与误检率、逐图 F1、SECOND 方向分项、调用次数

工具

编号动作谁决定做什么用在
T1看全局程序渲染全图缩略图，标出连通域编号v1 自主式
T2放大程序裁剪区域，输出 T1、T2 近景和当前掩码叠加图A、B、C
T3核实MLLM回答这里是否有 c 的变化，给出是否、伪变化类型和理由A、B
T4删除程序从掩码中去掉一个连通域A
T5新增MLLM 画框MLLM 在放大区域里画框，SAM 把框变成掩码，两期各分一次取并集B
T6精修程序用框或点提示 SAM 重新分割一个连通域C
T7找可疑区域程序按类别生成待查清单：初始化分数接近阈值的区域、SAM3 按类别文本两期分割的差异、AnyChange 提议中属于 c 的部分B
T8结束程序预算用完或队列为空全部

v0 与 v1

v0 编排式

程序按 A → B → C 的顺序把待查项交给 MLLM。MLLM 只做 T3 核实和 T5 画框，其余动作由程序执行。目的是先把整个流程跑通。

v1 自主式

MLLM 看完全局后自己决定下一步放大哪里、做什么、何时结束。v1 与 v0 的差，就是“自主决策”的价值。要专门处理停止时机和首步定位。

M3
加阶段 B：补漏

M4
加阶段 C：精修
边界与 F1c
M5
v1 自主式
相对编排式的提升与调用次数
M6
消融
去动作、换初始化、换 MLLM、去口径卡
