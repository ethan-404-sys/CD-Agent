# 任务：实验 6j（补充），遥感预训练 MLLM 的零样本变化判断

给服务器上的 Claude。前置结果见 `results/exp3_mllm_verify.md`（千问零样本）、`results/exp6b_verifier.md` 第 4 节（V2：Qwen3.5-4B + LoRA）、`results/exp8_object_pool.md`（对象池与去误检单元）。代码沿用 `code/probe/exp3_mllm.py`、`exp6v2_*.py` 的裁块、提示词和读数方式。本实验**只做零样本推理，不训练**（第 3 步除外，且需 Ethan 批准）。

## 为什么做
- exp3 和 V2 用的都是千问（Qwen3.5-4B、qwen3.7-plus），没有专门的遥感预训练。零样本 AUC 约 0.74–0.89；V2 微调后在 SECOND 上约 0.81，不如只用元数据的 V1（0.87）。
- Ethan 的假设：通用模型不认识遥感地物，这是 MLLM 判断变化表现差的原因之一。
- Mini-InternVL2-DA-RS（OpenGVLab，1B / 2B / 4B）是官方做过遥感领域适配的版本。**注意**：据其论文（arXiv 2410.16261，表 10），遥感训练数据为 GeoChat 指令集、RSVQA-HR、FIT-RS VQA、DIOR-RSVG 和 20% 通用数据，**全是单张图像任务，没有双时相或变化数据**。所以它可能改善“认地物”（如 WHU 上草地变停车场被当成建筑变化），未必改善“比较两期”（季节、色调、错位造成的伪变化）。
- 本实验回答：只换成遥感预训练的模型，零样本判断变化能好多少；好处集中在哪类错误上。

## 规则
- 不训练、不微调（第 3 步除外）；不调用外部 API。
- 允许下载 Mini-InternVL2-DA-RS 的官方权重（1B、2B、4B）及其推理代码依赖；下载不了就停下报告。
- 与千问对照时，**样本、裁块、红框 / 红色轮廓、提示词、读数方式全部相同**，只换模型。
- 单项预计超过 12 GPU 小时先报告。

## 模型
- 主模型：**Mini-InternVL2-4B-DA-RS**（与 Qwen3.5-4B 规模相同）。
- 规模对照：1B、2B 版本，只在第 1 步的 LEVIR / WHU 集合上跑。
- 对照组（已有结果直接复用，不重跑）：exp3 的 Qwen3.5-4B、qwen3.7-plus；V2a；V1 无骨干；检测器平均概率。
- 第 0 步：确认权重来源（Hugging Face 仓库名）、显存占用、是否支持多图输入；若不支持多图，把 T1、T2 左右拼成一张图（中间留白分隔，写明），并在 exp3 的同一批样本上用千问也跑一次拼图版本作对照。

## 读数
- 与 exp3 相同：强制前缀 `{"change": "` 后取 “yes” 与 “no” 两个词元的归一化概率作为 P(yes)；同时记录口头置信度。报告两个词元合计概率质量；若明显低于 1（如 < 0.9），说明分词方式不同，改用 logit 差并写明。
- 指标：AUC（2000 次自助法 95% CI）、yes/no 回答准确率、各来源回答“是”的比例；与对照组在**同一批样本**上比较。

## 第 1 步：exp3 原样本（LEVIR、WHU，必做，最便宜）
- 样本：`exp3/<数据集>/candidates.jsonl` 与 `inputs/` 原样复用（LEVIR 505、WHU 543），提示词用 `exp3_mllm.py` 中对应数据集的 `PROMPT` / `GENERAL_PROMPT`。
- 1B、2B、4B 都跑。输出格式同 exp3 的结果表（main、detector-positive、low-threshold、recall-side 四个子集）。
- 若 exp3 已在 SECOND / SYSU 上有千问结果（`results/exp3_error_examples*/` 中有 second、sysu 样例），同样用 4B 在这两个数据集的原样本上跑一遍。

## 第 2 步：V2 测试抽样（SECOND，必做）
- 样本：6b 第 4 节中 V2 测试用的 6,000 个分层抽样切块，近景输入与 V2 完全相同（`exp6v2_data.py` 的渲染，384 像素，红色轮廓）；加权方式同 6b。
- 只跑 4B。与同样本上的 V2a（0.814）、V1 无骨干（0.873）对照。
- 另取其中 1,000 个，加跑一个“近景 + 上下文”版本（上下文裁块同 6g 审核页 `exp6g_page.py` 的 `context_box`），四张图依次为 T1 近景、T2 近景、T1 上下文、T2 上下文；回答“上下文有没有帮助”。千问 Qwen3.5-4B 零样本在同 1,000 个上也跑两种版本作对照。

## 第 3 步（条件执行，需 Ethan 批准）：换底座重训 V2
只有当第 2 步中 4B 零样本 AUC 比 Qwen3.5-4B 零样本**高 0.03 以上**时，才提出此步：按 V2a 的完全相同设置（样本、LoRA 参数、轮数、选检查点规则）把底座换成 Mini-InternVL2-4B-DA-RS，估算 GPU 小时后**先停下报告**，等 Ethan 决定是否运行。

## 第 4 步：双时相遥感 MLLM 调研（只查，不跑）
查以下模型是否有公开权重和推理代码、训练数据是否含双时相变化任务、能否接收两张图：GeoLLaVA（arXiv 2410.19552）、TEOChat，以及调研中发现的其他用双时相数据训练的遥感 MLLM。列一张表，给出是否值得纳入下一轮对照的建议。

## 错误分析
从第 1、2 步各抽 10 个“千问判错、InternVL 判对”和 10 个“InternVL 判错、千问判对”的样本，存并排图（同 exp3 判错样例格式），每张一句说明，归为：认错地物 / 季节或色调 / 配准错位 / 真值可疑 / 看不清。

## 判断问题
1. 只换成遥感预训练模型，零样本 AUC 比千问高多少？是否超过检测器平均概率和 V1？
2. 提升集中在哪类错误上（认地物 vs 比较两期）？与“训练数据只有单图任务”的预期是否一致？
3. 1B / 2B / 4B 之间差多少？
4. 加上下文视图后，两个模型分别变化多少？
5. 是否值得做第 3 步（换底座重训）？第 4 步中哪个双时相模型值得纳入？
