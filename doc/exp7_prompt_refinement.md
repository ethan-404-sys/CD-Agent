# 任务：实验 7，确认后的掩码精修（提示方式对比）

给服务器上的 Claude。前置：`doc/eval_metrics.md`（统一指标，先跑完它的基础表）、`results/exp2_oracle.md`（SAM3 真值框上界）、`results/exp4c_end_to_end.md` 和 `results/exp5c_end_to_end.md`（候选框提示 SAM3 的结果）、`results/exp6b_verifier.md`。本实验**不训练任何模型**。

## 为什么做
- 现在的流水线把确认通过的 SLIC 切块整块并入。像素 F1 能涨，但边缘是台阶状锯齿（`results/pipeline_figs/test_987/final_mask.jpg`），不能称为高质量掩码。
- 之前用 SAM3 框提示效果差（exp4c 只有 +1.46），原因是框取自又大又松的整片候选，不是提示方式本身不行；真值紧框下 SAM3 补漏可达 +7.81（exp2）。
- 本实验只回答一个问题：**在"哪些区域要补"已经确定之后，用什么提示方式能让补进来的掩码形状最好，同时不损失像素 F1。** 它不改变"模型只做判断"的主线，是主线的配套模块。`doc/eval_metrics.md` 的 2c 是本实验的最简版本，本实验做完整对比。

## 设定
**确认结果（输入）**，两种都做：
- **O 设定**：切块级 oracle 确认（B+G0.05+H1，与 exp5c 同口径），作为上界；
- **V 设定**：V1 无骨干，B+G0.05+H1，验证集阈值 0.820（6b 主结果），作为实际情况。

确认通过、彼此相邻的切块先合并成连通域，以下称"确认区域"。精修只作用于确认区域；检测器原预测不动。去误检一侧不做精修。

**数据**：SECOND 为主；SYSU 同样做一遍；LEVIR、WHU 做 O 设定作为对照（建筑类，SAM 擅长）。提示方式和参数只在 SECOND 交叉拟合验证集（297 张）上选，测试集每种最终方案只评一次。

## 提示方式（逐个比较）
在同一确认区域上：
- **P0 不精修**：整块并入（现状，基线）。
- **P1 紧框**：确认区域外接框。
- **P2 紧框 + 1 正点**：正点取区域内离边界最远的像素（同 exp2）。
- **P3 紧框 + 多正点 + 负点**：区域内按距离变换取 3 个正点；负点取区域外扩 10 像素环带中检测器概率最低的 2 个像素。
- **P4 掩码提示**：把确认区域缩放成 SAM 的低分辨率掩码输入，可与 P2 组合。
- **P5 只用点**：P3 的点，不给框。
- **P6 多掩码选择**：SAM 多掩码输出，选与确认区域 IoU 最高的一个（对比默认的单掩码输出）。
- **P7 两轮迭代**：第一轮用 P2；第二轮在 SAM 掩码与确认区域分歧最大处各加 1 个正点或负点再跑一次。

**用哪一期影像提示**：t1、t2 各跑一次，比较三种选法：只用 t2；只用 t1；取 SAM 置信分数高的那一期。写明新建类和拆除类分别哪种更好。

**怎么和确认区域合并**，三种都比：替换；与确认区域外扩 r 像素（r = 3、5、10）取交；与确认区域取并。

**模型**：SAM3（已有）、SAM ViT-H（AnyChange 用的同一个，已有）。服务器上已有的其他 SAM 变体可以一并测；不新下载模型，RingMo-SAM 等待 6d 确认后再说。

**非提示的对照**：检测器软边界（确认区域内概率 > 0.05）、形态学平滑（同 `eval_metrics.md` 的 2a、2b）；如果服务器已有 OpenCV 的导向滤波（`cv2.ximgproc`），加一个导向滤波平滑；没有就跳过，不装新包。

## 评估
- `doc/eval_metrics.md` 的全部五组指标，重点看：像素 F1、IoU、Boundary F1（d = 2、5）、Boundary IoU、边界粗糙度、目标 F1、每图新增误检目标数、逐图下降占比。
- 另报告：SAM 掩码与真值的 IoU，按面积分桶（< 100、100–1,000、> 1,000 像素）和变化类型（新建、拆除、改建、植被互变、地表与植被互变、水体）拆分。
- 每种方案的推理耗时（每张图秒数）。

## 判断问题（写进 summary）
1. O 设定下，哪种提示方式能在不降低像素 F1（与 P0 相比下降不超过 0.3）的前提下，让 Boundary F1 和边界粗糙度明显改善？
2. V 设定下，精修是放大了误检（把错补的区域画得更大），还是缩小了误检？像素 F1 和每图新增误检目标数怎么变？
3. 哪类变化适合 SAM 精修，哪类不适合（例如植被、地表这类成片变化）？是否需要按类型或面积决定"精修还是不精修"？
4. SECOND、SYSU 与 LEVIR、WHU 的结论是否一致？

## 优先级
P0、P1、P2 加三种合并方式，O 设定 → 同样的方案在 V 设定 → P3–P7 → t1/t2 选择 → SYSU → LEVIR/WHU。单项预计超过 12 GPU 小时先报告。
