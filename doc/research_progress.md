# 科研进度总览（截至 2026-10-21）

## 课题与方向演变
- 起点：给遥感变化检测器做"掩码精修 agent"（MLLM 看掩码 → 调 SAM3 / SimpleClick 修）。旧原型 Chang-Agent 在 LEVIR 上闭环收益很小。
- 2026-10-15 重定位：召回优先，检测器掩码只是先验，agent 负责找漏检和确认。导师要求：不能放过漏检。
- 2026-10-18 任务定义：变化图的区域级校正，检测器无关的后处理，补漏为主，同时去误检。
- 2026-10-21 调整（与师兄讨论）：两手准备并行。（1）漏检找回；（2）MLLM 借助提示调用 SAM3 等工具优化掩码，向精修上界和补漏上界靠拢（exp7）。数据集定为 LEVIR-CD / WHU-CD / SECOND / SYSU-CD 四个，先跑出 baseline。SECOND 问题多但没有替代品，继续使用。
- 分工：服务器 Claude 跑实验（doc/ 任务 → results/ 结果）；GPT / Codex 做文献检索和交叉审核。

## 流水线（定型于 exp5，exp8 正在改）
找候选（AnyChange H1、SAM3 六类做差 B、检测器低阈值 G0.05、建筑实例差 C）→ SLIC 切细 → 验证器逐块打分 → 补入高分漏检块 / 删除低分预测块。exp8 改为：跨来源去重、以对象为单位判断，不再默认切 SLIC。

## 每个实验证明了什么
| 实验 | 证明了什么 |
|---|---|
| exp1 误差分解 | LEVIR/WHU（F1 92–93）主要错在边界；SECOND 主要错在整目标漏检（36%），降阈值补不回来。 |
| exp2 SAM3 oracle | 修边界上限 +0.5～1.6；补漏上限 LEVIR +0.5、WHU +1.2、SYSU +1.9、SECOND +7.8。 |
| exp3 零样本 MLLM | MLLM 偏向答"变了"，当裁判不如检测器自身概率。 |
| exp4–5 零样本流水线 | 四源并集覆盖 52% 的无信号漏检目标；完美确认 + 切细并入：SECOND +6.96～+8.50，SYSU +2.96（不切细 +2.21）。零样本确认全负（SECOND −0.73，SYSU −0.19）。 |
| exp6a 交叉拟合 | 三折重训 MambaSCD 得到无偏训练候选，留出 F1 71.04 vs test 74.17。 |
| exp6e 去误检上界 | 完美删除误检块：SECOND +5.74、SYSU +4.07；检测器概率当删除依据 ΔF1 ≈ 0。 |
| exp6b / 6f 验证器 | 6b 四个版本中 V1 无骨干 AUC 0.874 最好，测试 ΔF1 全负（6b 最好 −0.20），召回 80% 时补入像素精度 21%，门槛 37%。骨干版第 1 轮就背样本。V2（Qwen3.5-4B LoRA）抽样 AUC 约 0.81，不如 V1。6f 各变体都未转正：测试 AUC 最高 0.8751、像素精度最高 22.07%（均为 B2 PCA16，与 none 差距很小）；实际并入时测试 ΔF1 最接近零为 −0.01（A2 DINOv3），其余“0.00”是不并入。 |
| exp6h 时相约束 | 两种结构上都无效。 |
| exp6i 配准偏移 | 偏移普遍（可估计的负例中 57% > 3 像素；测试负例约 84% 无法估计），以局部为主；与 V1 失败关系弱，暂不处理。 |
| exp6g 标签噪声审核 | Ethan 盲审 300 个独立切块（另 20 个重复项，自一致 16/20）。审核者非专家，答案只作参考，不当真值。排除跳过 / 看不清后，与官方真值不一致：S1 13/55、S2 12/50（约 24%），S3 高分负例 36/55（65%）；S5 中可判断的植被 → 植被正例（均为 tree ↔ low vegetation）9/16 判为没变，目测多为季节性（未单独记录原因）。S1+S2 中 105 个有明确答案的样本上，V1 对官方真值 AUC 0.910、对审核答案 0.849（未加权）：V1 的排序更贴近官方真值；是否因为真值含季节性变化，尚未直接验证。 |
| exp6g 全切块图 | test_759 一图 1,302 切块，只来自 221 个候选（按来源与候选号回并，含 pred）；86% 来自 SLIC 切分（目标尺度约 298 像素，实际切块面积中位 164），六个来源不去重。该图负例以没变建筑的碎块为主；训练池整体是否如此未统计。 |

## 当前判断（2026-10-21）
1. （推测，未经对照实验验证）V1/V2 失败可能有相当一部分来自数据：候选碎、重复、标签纯度低；SECOND 真值对季节性植被、同类外观变化（如屋顶换色）的标注口径疑似不一致（待专家复核）。
2. SECOND 照常使用，主结果按原始真值报告，争议类别的影响单独量化；SYSU（只有二值标签）作对照，判断问题出在数据还是方法。
3. 是否把季节性植被、屋顶换色算作变化，正在请导师确认（例图在本仓库 `figures/exp6g/gt_clean/`；项目文件中另有 `label_noise/teacher_examples/`）。test_518 最清楚（相邻两栋同样换色的厂房一栋标、一栋不标，看图判断，待复核）；test_759 有争议（可能是真实生长）；test_900 被标为变化的位置 t1 是裸地，属于真实变化，不能当季节性例子。
