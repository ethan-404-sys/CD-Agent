# exp8 去重例图

用于检查跨来源去重的效果。生成脚本是 `code/probe/exp8_dedup_viz.py`。原图为 150 dpi PNG，为减小仓库体积转成了 JPEG（质量 88）。

## 每张图的排布

- **上排**：t1、t2、真值、真值轮廓（红色，叠在 t2 上）。
- **下排**：四种去重方式。每个对象一种颜色，轮廓叠在 t2 上，标题写对象数。
  1. **no merge**：原始候选，不合并。
  2. **direct pairs**：两个不同来源的候选满足 IoU ≥ 0.5，或较小者有 ≥ 80% 落在较大者内，就合并为并集。每个候选只按 IoU 最高的一对合并一次，不传递。
  3. **transitive**：同样的条件，用并查集传递合并，可能把一串候选连成一个大对象。
  4. **NMS**：按面积从大到小保留代表掩码，抑制与它满足条件的其他候选，不取并集。

## 候选来源

- SECOND：B、G0.05、H1。
- SYSU：B、G0.05。
- 与 5c 相同。同一来源内部的候选不合并。

## 请重点看

- 传递合并是否把明显不同的地物连成了一个对象。例如 test_1670 中，道路两侧的厂房被连成一个红色对象。
- 直接对合并后，同一地物上重复的轮廓是否还很多。
