## 1. 哪类误差占大头

| | LEVIR | WHU | SYSU | SECOND |
|---|---:|---:|---:|---:|
| 边界误差占误差像素 | **74%** | 47% | 45% | 15% |
| 部分命中 | 11% | 17% | 27% | 31% |
| 整目标漏检 | 9% | 19% | 15% | **36%** |
| 整目标误检 | 6% | 17% | 13% | 18% |
| 无信号漏检占真值像素 | 1.2% | 2.5% | 4.3% | **14.9%** |

- **LEVIR 以边界为主**，部分命中也主要是相邻房屋粘连。**数据越“通用”，漏检越重**，SECOND 上漏检和部分命中合计占 67%。
- **建筑数据集的漏检主要是小目标**（< 100 px 的漏检率 48–87%）。**SECOND 上难漏的是语义变化**：新建建筑的无信号漏检像素只有 1.8–5.4%，而改建（建筑→建筑）为 40%，植被相关变化 25–43%，地表↔植被 21–26%。
- **降阈值几乎补不回漏检。** LEVIR/WHU 上 F1 单调下降，漏检目标的概率接近 0。SYSU/SECOND 上降到 0.2–0.4 有 +0.1 到 +0.3 的小收益，阈值未校准，但再往下误检迅速增加。

## 2. 精度侧和召回侧的上界（SAM3 + 真值框提示，F1 变化）

| | LEVIR | WHU | SYSU | SECOND |
|---|---:|---:|---:|---:|
| 2a 精度侧：命中目标全部换成 SAM3 | −1.49 | −0.10 | −3.49 | +1.08 |
| 2a_select：只在 SAM3 更好时替换（完美判断器） | +0.50 | +0.79 | +1.62 | +1.50 |
| **2b 召回侧：补齐整目标漏检** | +0.50 | +1.18 | +1.89 | **+7.81** |
| 2c：再补部分命中 | −0.09 | +1.03 | +1.37 | +3.03 |
| 2a_select + 2b（两侧都做对） | +1.00 | +1.95 | +3.48 | **+9.05** |
| SAM3 对全部真值目标的平均 IoU | 0.86 | 0.91 | 0.78 | 0.71 |

- **精度侧在四个数据集上都不值得作为主线**：即使有完美判断器，上界也只有 +0.5 到 +1.6。
- **召回侧的上界随数据变“通用”而迅速增大**：从 +0.5（LEVIR）到 +7.8（SECOND），而且不需要判断器就为正。
- **SAM3 在通用变化上的分割质量明显下降**（成片地物的边界含糊），但对漏检目标仍可用：IoU ≥ 0.5 的比例，SECOND 85%，其他数据集 95–98%。
- 以上都是提示完美时的上界，实际 agent 需要自己找到漏检位置。

## 3. MLLM 能否胜任验证（零样本，AUC）

| | LEVIR | WHU | SYSU | SECOND |
|---|---:|---:|---:|---:|
| 检测器已预测：命中 vs 误检（4B / plus / 检测器） | 0.74 / 0.82 / **0.94** | 0.79 / 0.85 / **0.98** | 0.79 / 0.73 / **0.97** | 0.84 / 0.81 / **0.93** |
| 降阈值新区域 | 0.57 / 0.67 / 0.43 | 0.70 / 0.71 / 0.45 | 0.61 / 0.65 / 0.60 | 0.64 / 0.60 / 0.61 |
| 召回侧：漏检 vs 未变化（4B / plus / 检测器） | 0.79 / 0.89 / 0.92 | 0.89 / **0.93** / 0.93 | 0.77 / 0.71 / **0.91** | 0.71 / 0.81 / **0.88** |

4B 为本地 Qwen3.5-4B，plus 为百炼 qwen3.7-plus。召回侧负样本在 LEVIR/WHU 是“未变化建筑”，在 SYSU/SECOND 是尺寸匹配的随机未变化框，两者不可直接比较。LEVIR/WHU 的降阈值新区域正样本只有 21 / 43 个。

- **MLLM 在四个数据集上都不能作为检测器输出的过滤器**：它偏向回答“是”，对误检回答“是”的比例为 48–92%。
- **只有在建筑数据集的召回侧，百炼能与检测器持平**（WHU 0.93）。在通用变化上，MLLM 在所有子集都不如检测器的低概率排序。更强的 qwen3.7-plus 在 SYSU/SECOND 上并不比 4B 好，因为它更偏向回答“是”。
- 降阈值新区域上，三者在通用变化上都接近随机（0.60–0.65）。

## 4. 对主攻方向的判断

1. **召回侧值得做，精度侧不值得。** 召回侧的空间集中在通用变化和语义变化上：SECOND 上补齐漏检的上界是 +7.8，LEVIR 只有 +0.5。建筑数据集上召回空间很小，主要剩边界误差，而精度侧上界又低。
2. **召回 agent 的瓶颈在“找”和“确认”，不在分割。** 检测器对漏检几乎没有信号（概率图降阈值无效），SAM3 在给出位置后分割质量足够。需要独立的候选来源，例如两期语义分割的差异、建筑实例差异、网格扫描。
3. **确认环节不能直接依赖零样本 MLLM。** 在建筑上它能接近检测器（WHU 0.93），在通用变化上明显不足，且有强烈的“有变化”偏向。更可行的是结合检测器的低概率（排序 AUC 0.88–0.93）、两期语义一致性，或训练一个专门的验证器。
4. 若导师要求“不能放过漏检”，建议以 SECOND 型数据（多类别语义变化）作为主要评测场景，LEVIR/WHU 作为建筑场景的对照。在 LEVIR 上，召回 agent 的收益上限约 +0.5 F1，很难体现方法价值。

## 未完成与限制

- **GPT（gpt-6.1-sol，LEVIR/WHU）补测未完成**：本地转发通道对图像请求持续断开，可能是订阅侧限流。只拿到 122 条，不足以计算 AUC。已得部分显示 GPT 同样偏向回答“有变化”（LEVIR 误检上 79% 答“是”，n = 19）。
- **检测器不够多样**：LEVIR/WHU/SYSU 只有 SChanger 一个家族，SECOND 只有 MambaSCD。不同检测器的误差结构可能不同。
- **SECOND 的口径调整**：按变化类型拆分后产生大量 < 20 px 的标注碎片（占目标数 47.5%、像素 0.1%），目标级比例应参考 ≥ 20 px 的统计和像素级指标。

## 实验 4：召回侧的候选生成与确认（SECOND 为主，SYSU 对照）

详见 `exp4a_candidates.md`、`exp4b_confirm.md`、`exp4c_end_to_end.md`。

1. **哪类候选来源最值得留下**：
   - **SAM3 六类语义做差（B）**：覆盖率最高的非网格来源（SECOND 19.7%，SYSU 34.7%）。
   - **检测器概率 > 0.05 的新增区域（G0.05）**：覆盖率和候选数的折中最好，每图前 10 个候选就覆盖 SECOND 13.9%。
   - **建筑实例差（C）**：改建（建筑→建筑）几乎只有它能找到。
   - 编码器特征差（D）和同类检索（E）可以放弃。
   - 所有来源都存在两个问题：候选区域偏大（去掉面积上限后覆盖率翻倍）和纯度极低（2.5–20%）。
2. **真实候选上最好的确认信号**：检测器自己低于 0.5 的概率。合并两个来源时 AUC 为 0.79 / 0.75；只看 B 的候选时为 0.87 / 0.90。两期语义一致性约等于随机，MLLM 只有 0.61–0.65，组合也没有增益。
3. **不靠真值能拿到上界的几成：拿不到正收益。** 在所有确认阈值下 F1 都下降（SECOND −8.6 到 −17.2，SYSU −1.4 到 −9.6）。确认完美时，SECOND 只拿到上界的约 19%（+1.46 / +7.81），SYSU 约 96%（+1.81 / +1.89）。

**瓶颈排序：确认 > 候选粒度与补全 > 覆盖率。** 召回 agent 要成立，需要一个在 5–27% 正例率下仍能把误检压到很低的确认器，现有零样本信号做不到。下一步可以考虑：
- 训练专门的验证器；
- 先把候选切细再补全；
- 把目标改为输出按风险排序的人工复核清单。

## 实验 5：召回侧补测（AnyChange、RemoteCLIP、检测器复检、补全方式）

详见 `exp5a_anychange.md`、`exp5b_confirm.md`、`exp5c_end_to_end.md`；资源见 `env.md` 的“实验 5 资源”一节。

**找。** 原版 AnyChange 全图模式（H1，SAM ViT-H）是 SECOND 上覆盖率最高的单一来源：29.3%，B 为 19.7%；在建筑类变化上尤其强（31–38%）。换成 SAM3 的同一做法（H3）只有 6.5–9.8%，原因是 SAM3 交互头得到的类别无关提议太少。点查询（H2）基本无效。SECOND 上 B + G0.05 的覆盖率为 29.8%，加 H1 后为 48.6%，再加 C 后为 52.2%。

**确认。** RemoteCLIP（AUC 0.51–0.67）不可用。检测器原尺寸复检与原始概率持平（0.74–0.84），放大复检更差。加入所有新信号的逻辑回归只有边际提升（最好 0.85，在 H1 候选上）。

**补全。** 4c 的“候选框提示 SAM3”严重低估了“找”的贡献。oracle 确认后直接并入候选区域为 +3.05；用超像素切细后直接并入，SECOND 为 **+6.96**（加 H1 为 +8.50），SYSU 为 +2.96。

### 判断问题

1. **有没有确认信号或组合，在平衡样本上召回 80% 时误检率降到 15% 以下？——没有。** 最低为 29%（H1 候选，检测器概率或原尺寸复检）。4b 候选上为 33%（SECOND）和 41%（SYSU）。按真实候选池加权后，召回 80% 时补入候选中真变化只占约 20–29%。
2. **不靠真值的端到端有没有设定拿到正的 ΔF1？——没有。** 最好的是切块级检测器概率确认 + 切细后直接并入，仍为 SECOND −0.73（加 H1 为 −0.74）、SYSU −0.19。所有阈值、粒度、候选组合都为负。
3. **oracle 确认下换了补全方式后，SECOND 能拿到上界的几成？——约 9 成**：+6.96 / +7.81 = 89%；加 H1 后为 +8.50，超过 2b 上界，因为还补到了部分命中目标缺失的像素。这是切块级 oracle，比实验 2 宽松。它说明“找 + 切细 + 直接并入”在确认完美时足以拿到大部分上界。

**结论：问题 1 和 2 都是否定的，零样本信号无法完成确认，确认环节必须训练。** 同时，问题 3 说明一旦确认可靠，现有的“找”和补全已能兑现大部分上界，所以训练漏检验证器的投入有明确回报。建议下一个实验训练漏检验证器，有三点：
- **在切块级做判别**，输入两期裁块与检测器概率；
- **训练样本取自真实候选池**（B、G0.05、H1 的切块），正例率约 5–29%，按真实正例率评估；
- **目标**：召回 80% 时，平衡样本上的误检率低于 15%，或真实池中补入切块的像素精度高于当前 F1 的一半（SECOND 约 37%，SYSU 约 42%）。并入区域的像素精度超过 F1/2 时，F1 才会上升。

**已得到的结论。**

1. **交叉拟合样本可以代表测试分布。** 交叉拟合检测器在没见过的训练图上 F1 71.04（测试 74.17），精度几乎相同（77.0 vs 77.6），无信号漏检占真值像素 17.8%（测试 14.9%）。差别集中在召回，原因是每折只用 63% 的训练图；训练候选池的正例会略多于测试池，6b 选阈值时需注意。
2. **去误检的空间与补漏相当。** 按切块删除误检（oracle）：SECOND +5.74，SYSU +4.07；只删整块全错的区域只有 +2.43 / +1.17。补漏一侧的切块级 oracle 为 +6.96 / +2.96（实验 5c）。同一个切块级验证器若同时做补漏和去误检，可争取的空间大致是只补漏的两倍（两侧作用于不同像素，但合并效果需实测）。
3. **切细对去误检同样关键**：切细后能删掉 SECOND 67.5% 的误检像素，误删的 TP 只占 0.1%；不切细只能删 29.6%。

**判断问题。**

1. 训练后的验证器能否让并入切块的像素精度超过 F1/2（SECOND 约 37%）？——**V1 不能**：召回 80% 时测试集像素精度最好 21.3%（无骨干基线），加图像特征的三个骨干为 16.5–18.5%。学习曲线显示三个骨干版本从第 1 轮起就在背训练样本（训练子集 AUC 升到 0.98 以上，验证 AUC 不升、验证 loss 上升），无骨干基线没有这一现象（`figures/exp6f/v1_curves.png`）。V2a / V2c 也不能：同一批 6,000 个测试抽样上 AUC 0.814 / 0.811，低于 V1 无骨干的 0.873。
2. 不靠真值的端到端 ΔF1 在 SECOND 上是否转正？——**V1 不能**：阈值在验证集上选、验证集 ΔF1 为 +0.11 至 +0.63，测试集全部为负（最好 −0.20）。疑与训练池/测试池检测器概率分布不同有关。对照：零样本最好 −0.73，切块级 oracle +6.96 / +8.50。V2 待定。
3. 换检测器、换数据集后是否仍为正？——**不再检验**：V1 在 SECOND 上已不能转正，泛化检验没有意义（6c 不做）。
4. V2 相对 V1、V2b 相对 V2a 是否有收益？——**V2 不如 V1**。验证抽样 3,000 个 AUC：V2a 0.842、V2b 0.799、V2c（先答后推理）0.839，V1 无骨干全验证集 0.867；测试抽样 6,000 个：V2a 0.814、V2b 0.779、V2c 0.811，V1 同样本 0.873。先推理（V2b）更差，推理放在答案后（V2c）与只答相同。全池推理需 330 GPU 小时以上，V2 只报告抽样结果。
5. 去误检的上界有多大？——**SECOND +5.74，SYSU +4.07**（切块级 oracle）。V1 验证器在 pred 切块上 AUC 0.70–0.785，未超过检测器自身平均概率（0.784），去误检 ΔF1 约 0；用 pred 切块重训的版本不做，已由 exp8 第 4 步的去误检判别器回答（SECOND −0.0008，SYSU −0.14）。

**实验 6 剩余**：只有 6g 干净子集上的正式统计。6c 与 6e 的 `--include_pred` 重训于 2026-10-23 决定不做（原因见上表）。

## 实验 8 补充 2：按漏检格看分流与判断器（2026-10-24，第 1、1b、1c、1d、2 步完成）

- **判断器按去向拆开（第 2 步，测试部分）**：
  - V1 在补漏总体上不接近 0.5，反而高于精修总体：SECOND 0.77–0.81 对 0.71–0.74，SYSU 0.87 对 0.74。补漏内 ①+② 正例对补漏负例为 0.73–0.82。

  - 元数据逐项：在 ①+② 上，检测器概率均值单独排序就有 0.72–0.83，和完整 V1 相差不超过 0.01；面积和来源只有 0.41–0.70 的弱区分力。

  - 没有一格的去补漏比例变化超过 2 个百分点；SECOND 测试只有 3 个 ② 从精修改为补漏。
  - 把 ② 带去精修的大候选，其新增部分本身连成一片并在别处贴着 D，按与 D 的连通性拆不开。需要按候选自身切小，例如按成员原始掩码分别算 r，或限制面积。
- **两组候选的构成（第 1c 步，R(0.1)）**：
  - 补漏组 84–98% 的候选完全不含真值。新增像素精度高于 F/2、值得并入的：SECOND 每图 9–11 个（7–9%），SYSU 每图 3.5–3.7 个（5–6%），LEVIR、WHU 每图约 1 个以内。
  - 便宜预过滤里“新增 < 100 像素”最划算：每图去掉 32–45 个候选，①+② 漏检只损失 0.2–0.6%（SYSU 1.9–2.6%）。H1 只留前 10 会损失 2–6%。
  - 精修组候选的新增部分中位数是所补漏检的 2–7 倍，IoU 中位数只有 0.02–0.12。
  - 精修起点对比：
    - 把全部精修候选并入（起点 B），F1 比检测器本身低 5.6–12.0 个点（SECOND）、5.5–7.2 个点（SYSU）、25–37 个点（LEVIR、WHU）。
    - 全部挑对时（起点 B′）高 +4.2 到 +6.6 个点（SECOND）、+2.8 到 +3.6 个点（SYSU）。
    - SECOND 从 B 出发每图要删 4–5 万误检像素、24–34 个连通域。SYSU 每图只需删 3–4 块。
- **最终分流规则（第 1d 步，只用验证选）**：
  - 选中的做法是候选按成员分别算 r 分流，R(0.1)，不加预过滤。
  - SECOND 测试的 ①+② 覆盖从 53% 升到 58%，② 覆盖从 62% 升到 65%，③ ≥ 30% 误分 2.9%。
  - 没达到 70% 的目标：限制面积能到 60–66%，但 ③ 误分会升到 9–22%。
- **第 2 步按第 1b 步修正分流补报**：AUC 最多变化 0.01，结论不变。
