# OVCD-v0 第 3 轮后讨论：第 4 轮换 I-M-C 初始化

**同意第 4 轮换成 I-M-C 初始化，并把它排在上一轮建议的 B 大近景限制之前。** 新的同划分验证证据改变了上一轮的排序依据：I-M-C 的初始 F1^c 为 **73.008**，比 M-C-I 高 **15.185** 个百分点，比第 3 轮 k=50 的最终结果高 **12.125** 个百分点。它同时减少像素误检、像素漏检和整目标错误；M-C-I 即使使用真值选择最佳整块删除，F1 也只有 65.427。继续优先修补旧初始化的理由已经不足。

**同意方案主体：A 使用新连通域，验证集比较三种排序；B 使用全部 M-C-I SAM 提议，包括 M-C-I 已接受的提议，核实通过后直接加候选掩码；保持 C、k 和 a_share 的规则。** 需要明确三点：A 的借用属性只是排序线索；保留固定 `score_asc` 的对照，以区分换初始化与扩大排序搜索的贡献；第 4 轮 Agent 的增益必须相对 **73.008 的新 M0** 报告。现有分析支持开展这一轮，尚未证明 A/B/C 能继续提高新 M0。

本文只用 LEVIR 验证集 64 张 1024² 图作判断。F1、IoU、比例以百分数表示，差值为百分点。`RUN` 指 `../ovcd_v0_run`，代码路径相对 `../../CD-Agent`。只新增本文，外部代码及产物均只读。

**1. 同口径错误构成：I-M-C 改善明显，剩余错误更集中于已命中对象**

读取两种 M0 的真实 PNG 和同一份真值，使用 8 连通域。对象口径沿用 `common.object_counts`：一个对象与另一侧所有相交连通域的并集计算 IoU，低于 0.1 算整目标漏检或误检。因此“整目标漏检”也包括已有部分覆盖、但匹配 IoU 很低的对象，并不要求交集为零。

| 验证集指标 | M-C-I M0 | I-M-C M0 |
|---|---:|---:|
| 累计 F1^c / IoU^c | 57.823 / 40.670 | **73.008 / 57.490** |
| 累计精度 / 召回率 | 47.782 / 73.206 | **64.761 / 83.660** |
| TP | 2,061,666 | 2,356,097 |
| FP | 2,253,033 | 1,282,026 |
| FN | 754,602 | 460,171 |
| 真值对象数 | 2,788 | 2,788 |
| 整目标漏检数 / 率 | 1,203 / 43.15% | **764 / 27.40%** |
| 预测连通域数 | 2,253 | 2,243 |
| 整目标误检数 / 率 | 860 / 38.17% | **637 / 28.40%** |
| FP 占全部错误像素 | 74.91% | 73.59% |
| 逐图平均 F1，按 Agent 口径 | 46.560 | 60.270 |

I-M-C 少了 **971,007 FP、294,431 FN、439 个整目标漏检和 223 个整目标误检**。预测连通域总数接近，所以按每图连通域数分配 A 调用的规模仍相近。

逐图平均按 `common.image_f1` 的“双空得 1”规则计算。I-M-C 原 `metrics.json` 的 stitched 平均为 52.457，其双空图按 0 计；本次有 5 张双空图，改用 Agent 规则增加 5/64×100=7.8125 个百分点。累计指标与原文件完全一致。后续报告逐图平均时应统一这一约定。

误检像素沿用 `m1_errors.py` 的两类划分：

| FP 所在区域 | M-C-I：像素数（占 FP） | I-M-C：像素数（占 FP） |
|---|---:|---:|
| IoU<0.1 的整块误检对象 | 695,663（30.88%） | 227,926（17.78%） |
| 已命中对象上的多余像素 | 1,557,370（69.12%） | 1,054,100（82.22%） |

**I-M-C 剩余 FP 主要附着在已命中对象上，整块删除的处理空间相对变小。** 第二类包含轮廓外扩、连接多个区域等混合错误，不能全部称为窄边界误差。补充的几何检查显示：第二类 FP 中，距任一真值前景不超过 3 像素、采用棋盘距离的部分，M-C-I 为 482,223（30.96%），I-M-C 为 505,240（47.93%）；I-M-C 仍有 **548,860** 个这类 FP 距真值超过 3 像素。这里的 3 像素只作形状描述，不作为过滤或选参阈值，也不推断具体语义误判原因。

FN 分型直接调用 `m1_errors.cells(gt, m0)`，判定顺序为 **⑤→③→①→②**。先按真值对象拆出未覆盖连通块：对象或漏检块小于 20 像素归⑤；否则真值对象被 M0 覆盖至少 10% 归③；否则漏检块距 M0 的最小棋盘距离≤1 归①；其余归②。

| FN 类型 | M-C-I：像素数（占 FN） | I-M-C：像素数（占 FN） |
|---|---:|---:|
| ① 与 M0 相邻、对象覆盖不足 10% | 131,580（17.44%） | 25,574（5.56%） |
| ② 孤立漏检、对象覆盖不足 10% | 522,944（69.30%） | 241,329（52.44%） |
| ③ 已覆盖至少 10% 的对象上的剩余漏检 | 79,517（10.54%） | 163,427（35.51%） |
| ⑤ 微小对象或微小漏检块 | 20,561（2.72%） | 29,841（6.48%） |
| 合计 | 754,602 | 460,171 |

①②的绝对量大幅减少，③⑤的绝对量增加。这与更多真值对象被部分找出后，错误转为对象内部的剩余部分相容；分类基于各自 M0，不能把③⑤增加直接解释为同一批目标上的新增损失。②仍占一半以上 FN，补入阶段仍有必要，但需要检查现有候选来源是否能到达这些遗漏。

**2. 理想操作上限：A 约有 +3.18，完整真值补入约有 +5.37**

| 从各自 M0 出发的独立操作 | M-C-I F1（增量） | I-M-C F1（增量） |
|---|---:|---:|
| A*：最佳整连通域删除 | 65.427（+7.604） | **76.184（+3.176）** |
| B*：加入所有整目标漏检的完整真值掩码 | 69.853（+12.031） | **78.381（+5.374）** |

A* 直接调用 `best_deletion`：按每个预测连通域的真实精度升序，搜索使全验证集累计 F1 最高的删除前缀，不受调用预算限制。M-C-I 最佳删除 905 个连通域，I-M-C 删除 667 个。它也可能删除含有 TP 的混合区域，不能用“删除所有整目标误检”代替这项计算。

B* 沿用 `m1_errors.py`，加入当前 IoU<0.1 的所有真值对象，只计算此前未覆盖的像素。M-C-I 新增 659,178 TP；I-M-C 新增 **285,196 TP**，均不引入 FP。I-M-C 这 764 个漏检对象的总面积为 554,777，不能将整对象面积都算成新增 TP。B* 仍留有其他对象上的 FN，所以也不是把全部漏检像素补齐的上限。

两项均使用真值，是各自操作范围内的参考上限；它们都从原始 M0 出发，**增量不能直接相加**。A 删除会改变 B 的待补对象和当前掩码，真实 Qwen、候选形状和调用预算还会进一步限制收益。

**3. 新 B 队列的实际覆盖：保留 M-C-I 已接受提议有明确价值，覆盖总量仍有限**

本次从原始 M-C-I 验证集 NPZ 重建队列，沿用 `queues.py` 的完整规则：面积在 [50, 20,000]，被新 M0 覆盖≤50%；按 `sigmoid((score−cos145°)/0.05) × p_own × (1−p_other)` 降序；贪心去重，IoU>0.5 或当前提议至少 80% 落在先前提议中时丢弃；最后取前 N 项。新队列允许 `in_m0=True`。旧 M-C-I 对照保持原先的排除规则。

覆盖口径与 `m1_queue_diag.py` 一致：候选覆盖某个整目标漏检至少 30%，**或**候选自身至少 50% 落在该对象上，即算触及。表中的“命中候选并集 F1”也是原脚本口径：借助真值挑出所有触及漏检对象的候选，把完整候选掩码取并集后加到 M0。

| 初始化与 B 来源 | 前 N 项 | 触及漏检数 / 总数 | 覆盖率 | 命中候选并集 F1（相对 M0） |
|---|---:|---:|---:|---:|
| M-C-I，原 T7 | 20 | 253 / 1,203 | 21.03% | 61.595（+3.772） |
| M-C-I，原 T7 | 50 | 405 / 1,203 | 33.67% | 63.317（+5.494） |
| I-M-C，全部提议 | **20** | **85 / 764** | **11.13%** | **73.902（+0.894）** |
| I-M-C，全部提议 | 50 | 178 / 764 | 23.30% | 74.926（+1.918） |
| I-M-C，排除 M-C-I 已接受提议后重新排序及去重 | 20 | 40 / 764 | 5.24% | 73.374（+0.366） |
| I-M-C，同上排除 | 50 | 91 / 764 | 11.91% | 73.401（+0.393） |

前 50 项只用于说明截断损失，本轮仍建议固定 `b_max=20`。该命中候选并集会带入 FP；“触及目标”也不保证加入后对象 IoU 能越过 0.1。因此这项指标是**使用真值筛选的候选参考结果**，不是最佳候选子集的严格上限，也不是实际减少的整目标漏检数；它与上一节的完整真值 B* 不同。

I-M-C 前 20 项一共 1,280 个候选，其中 **796 个（62.19%）来自 M-C-I 已接受提议**，484 个来自未接受提议。前者触及 77 个漏检目标，后者触及 8 个，两个目标集合在这个队列内没有交集。按上述真值筛选后，全队列新增 **67,502 TP、37,092 FP**；其中已接受提议贡献 62,962 TP、36,065 FP。排除这些提议会丢掉主要的现成补充机会。

**允许进入 B，同时保留 Qwen 核实。** 如果将这 796 个已接受提议全部直接并入新 M0，实际新增并集只有 73,705 TP，却有 **568,108 FP**，新增像素精度仅 **11.48%**。M-C-I 的接受状态不能替代新状态下的加入判断。准确条件是“提议被新 M0 覆盖≤50%”；这些提议可能部分位于新 M0 内，不能笼统认为它们全在 M0 外。

预算还会进一步限制机会。在冻结新 M0、不执行任何删除或写入的描述性检查中，A 按 `min(连通域数, round(0.75k))` 消耗调用，B 取剩余额度允许访问的前缀：

| k | 全验证集 A 调用数 | B 可访问候选数 | 触及原始漏检数 / 率 | 剩余调用数 |
|---|---:|---:|---:|---:|
| 10 | 418 | 222 | 7 / 0.92% | 0 |
| 20 | 720 | 560 | 22 / 2.88% | 0 |
| 50 | 1,431 | 1,085 | 71 / 9.29% | 684 |

这是无写入的前缀检查，真实 B 写入会影响后续覆盖跳过，A 也可能新增漏检；这些数不是实际执行的上限或预测。它们说明，不能把完整前 20 项覆盖的 85 个目标视为所有预算都能利用的机会。保持 a_share=0.75 有利于本轮比较；是否重新分配 A/B 预算，应由本轮实际阶段收益和调用轨迹决定。

**4. 对具体设计的意见与第 4 轮执行约定**

**A 的连通域与属性：同意，但明确属性定义与缺省含义。** 使用拼接后的 I-M-C 8 连通域，面积取新连通域面积。沿用现有替代初始化实现：先关联至少一半提议面积落入该连通域的 M-C-I 提议，若没有则取任意重叠；`score` 为关联提议的最大 DINOv2 变化分数，`bprob` 为最大本期建筑概率，`bother` 取同一个最大概率提议的另一时相概率，并记录 `nprops`。最大 score 与最大建筑概率可能来自不同提议，这些属性也没有描述整块 I-M-C 区域的校准置信度。

没有任何重叠提议时，当前实现使用 `score=-1、bprob=bother=0、nprops=0`。验证集中这样的区域有 **103/2,243（4.59%）** 个，总面积 21,516，其中 TP 10,470、FP 11,046。虽有 85 个按对象口径属于误检，整组像素精度仍达 48.66%，不可据缺省分数直接删除。应保留 `nprops=0` 标记，单列访问和误删统计。

**A 排序：同意在 {score_asc, area_desc, area_asc} 内选，现有证据不足以固定沿用旧赢家。** 按每图 A 上限 8/15/38，使用真实精度决定最佳删除，得到：

| A 排序 | k=10 的理想 A F1 | k=20 | k=50 |
|---|---:|---:|---:|
| score_asc | 74.000 | 74.699 | **75.683** |
| area_desc | **74.334** | **74.783** | 75.496 |
| area_asc | 73.594 | 74.112 | 75.376 |

`score_asc` 在 k=10 会访问 99 个无重叠区域，占其 418 次 A 调用的 **23.68%**；这 103 个区域全部 FP 也只占总 FP 的 0.86%。它确实可能把短预算花在面积小的缺证据区域上。不过，上一轮已表明理想排序不保证实际 Qwen 排序收益，因此表格只支持重新比较，不据此直接指定 `area_desc`。

**单一主要因素的归因需要一个固定排序对照。** 第 3 轮固定 `score_asc`，第 4 轮增加三排序选择，搜索范围本身也发生了变化。建议主结果按提议比较三排序与原 τA 网格，再顺序选择 B、C；同时用同一份新调用缓存跑一条固定 `score_asc`、按原阈值网格选 A→B→C 的完整对照。两条都相对新 M0 报告；再用固定排序对照与第 3 轮比较，说明初始化及其必需的队列适配带来的变化。对照无需新增 Qwen 输入，但仍需执行其 B/C 选择与评测，不能把 A 阶段差值直接加到最终结果。

**B 来源和写入方式：同意全部提议、保持去重与面积范围、前 20 项、无 T5。** 上节数据支持保留 M-C-I 已接受提议；纯按原 `~in_m0` 过滤会降低覆盖。继续按当前 M 动态检查覆盖，核实达 τB 后直接加入候选掩码。近景≥512 的限制、队列扩至 50、新提示和新候选模型均留作独立后续因素；上一轮少数大近景候选的证据不足以直接适用于新队列。

**C 与选参：保持实现，重新选择门限并允许不修补。** 保留 k=10/20/50、a_share=0.75、原口径卡、近景方式和逐阶段选参规则。A 网格含 τA=0，B 含 τB=1.01，C 含 `none`，分别保留不删除、不加入、不修补的选择；另单列真正零调用的新 M0。τA=0 在当前实现中仍核实 A 并消耗预算，不能当作零成本跳过 A。保持累计 F1 四舍五入六位优先、再比较调用量的现有选参规则。

**调用与成本：新 A 需按新掩码生成输入，所有待访问候选必须有对应回答。** 使用独立 item/call 标识保存新队列，A 的同一个数字 uid 不代表旧轮同一个区域。现有 `calls.py` 的核实输入由两期图、候选轮廓、裁剪和提示组成；B 中视觉输入完全相同的候选可核实后复用旧回答，新候选需补调用。可以统一重建新一轮缓存，保证三种 A 排序可能访问的区域都已覆盖，并关闭 T5 画框调用。题述约 0.5 GPU 小时仍是估计，本次未验证；新初始化、M-C-I 候选准备、Qwen 核实和 C 修补成本应分开记录。

验收以同一验证集的 **M0→A→B→C** 为主：每档记录累计 F1/IoU/P/R、TP/FP/FN、整目标漏检与误检、统一口径的逐图平均 F1，以及调用数。A 单列删除 TP/FP 和 `nprops=0` 的行为；B 单列已接受/未接受来源、实际访问、接受、覆盖跳过及新增 TP/FP；C 单列修补前后像素与对象变化。必须展示相对新 M0 的净增益，并保留“不操作”的结果。完成验证选择后冻结配置，测试集只按既定流程评测，不反向选参数。本次仅交付分析，未启动第 4 轮。

**5. 第 1–3 轮哪些结论需要重检**

| 旧结论或经验 | 换初始化后需要检查什么 |
|---|---|
| 换初始化优先级低于 B 大近景限制 | 新验证集已经提供更强起点及同口径错误改善，应调整优先级；旧建议的证据前提已改变。 |
| A 采用 score_asc，τA=0.8/0.6/0.6 | A 的轮廓、属性来源和缺省分数分布变了；三排序与阈值都要重选，检查误删 TP。理想删除空间已从 +7.60 缩到 +3.18。 |
| A 值得占 75% 调用预算 | 连通域数量接近，但可删误检像素及核实收益不同；先保持份额完成本轮，再依据 A/B 实际收益讨论预算。 |
| T7 前 20 项能覆盖约 21% 整目标漏检 | 新 M0 下只有 11.13%，预算内前缀更少；必须重新测来源、排序及访问机会。 |
| B 接受候选主要来自低 p_own 的未接受提议 | 新前 20 项中 62.19% 已被 M-C-I 接受，分布已变化；旧 p_own 分组、useful AUC 和高置信误检比例均不能直接搬用。 |
| 无 T5 的增益和 τB=0.95/0.9/0.9 | 本轮仍保持直接加候选掩码，但旧收益幅度与最佳阈值没有迁移保证。新 M0 下实际新增像素与候选本身的精度更需分开。 |
| 拒绝近景≥512 可提高 B | 原证据集中于少数图和旧队列；重新描述新队列的尺度、误检与新增像素后，再决定是否另做单因素试验。 |
| C 的 0.8/0.8/0.7 门限带来小幅稳定像素收益 | 新起点更好，FP 更多附着于已命中区域；C 可能修边也可能损伤已有轮廓，应重选含 none 的网格，并检查对象错误。 |
| k 增大、扩队列或调排序具有旧轮同样的收益 | 需重新记录每图实际预算、前缀访问及覆盖跳过；全局剩余额度不能直接换算为可补目标数。 |
| Agent 提升约 1–3 点、缓存支持原排序比较 | 新 Agent 增益须相对 73.008 计算；新 A 轮廓与新增 B 输入需要新回答，旧缓存结果不能代表这一轮。 |

仍然成立的是若干计分与操作关系：累计 F1 与逐图平均的权重不同；高 `P(yes)` 和高新旧掩码 IoU 都不等于语义正确；B 必须检查实际新增部分。忽略计分中极小常数，一次补入使 F1 提高要求新增像素精度超过当前 F1/2，整块删除有利则要求被删区域精度低于当前 F1/2。新 M0 的这个参照值约 **36.50%**，旧 M0 约 **28.91%**，所以相同候选在两种状态下可能有不同的收益方向。这一像素收益参照值与 Qwen 的概率阈值 τA、τB 是不同的量。
