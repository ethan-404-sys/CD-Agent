补漏与去误检：方法流程

输入两期遥感影像，检测器给出初始变化图；候选工具寻找遗漏区域，验证器逐块打分，最后按阈值补漏或去误检。本页展示真实 V1/V2a 输出，同时保留 oracle 理想上界。

先看懂几个词

词意思
双时相影像 t1 / t2同一地点前后两期 RGB 影像，SECOND 为 512×512。
检测器MambaSCD-Base 输出变化概率和 0.5 二值图；下游校正使用已保存的二值 PNG。
真值（GT）人工变化标注；SECOND 的两期语义标签记录变化前后的六类地物。只用于训练标签和评估。
漏检 / 误检蓝色为漏检 FN，红色为误检 FP，绿色为正确预测 TP。
无信号漏检预测覆盖不足 10%、面积至少 20 像素的真值目标。历史统计按语义转移拆目标。
候选（来源）候选工具提出可能变化的区域：H1、B、G0.05、C1/C2。
覆盖率候选覆盖目标至少 50%，且候选面积不超过目标外框的 4 倍时算找到；统计无信号漏检目标。
纯度区域内真变化像素比例；来源面积合计按候选重复计数，全部来源并集另行去重。
切细 / 切块SLIC 根据两期颜色与位置划分超像素，大候选与超像素相交后形成切块。
验证器逐块判断变化的模型；补漏用高分块，去误检删低分块。
验证器 V1 / V2V1 为特征加 MLP，本页用 none 表格基线；V2 为 Qwen3.5-4B LoRA，直接看两期裁块。
补漏切块 / 去误检切块前者来自候选工具，后者来自检测器自身预测区域（pred）；V1 主模型仅用补漏切块训练。
oracle直接按真值挑块的理想上界。页面将其与真实验证器结果分别标注。
F1 / ΔF1F1 为精度与召回的调和平均；ΔF1 为校正后减校正前。页面 F1 用百分数，ΔF1 用百分点。
F1/2 门槛并入像素的真变化比例超过当前 F1 的一半时，像素 F1 才会上升；SECOND 约 37.08%。
AUC / 召回 80% 时误检率AUC 衡量排序；误检率为放过真变化的同时放过多少负例。验证阈值与测试 ROC 诊断分别标注。
交叉拟合（K 折）训练集分三折，用其余两折训练的检测器预测留出折，为训练验证器产生真实漏检。
SeKSECOND 语义变化指标，用于选择交叉拟合检测器检查点。
