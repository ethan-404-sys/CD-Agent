# 实验 8 补充 7：过滤后补漏组上的图像判断器

日期：2026-10-27。任务原文：`doc/exp8s7_image_judge.md`。

- 模型、阈值、α 和种子都只在验证部分选定。
- 冻结之后，测试部分只评了一批，这一批包含全部对照和 3 个种子。
- GPU 用量：按 Slurm 记账共约 3.5 GPU 小时，预算上限是 24 小时。

## 结论

1. **② AP 在测试上都有提高，但只有 SYSU 的晚融合达到 0.15。**
   - **SECOND**：图像判断器的 ② AP 在验证上是 0.206，在测试上降到 0.129。
     - 测试上仍明显高于元数据：D 是 0.087，M1-ign3 是 0.100，元数据重训是 0.102。
     - 图像减元数据重训的配对差为 +0.027，95% 置信区间 [0.020, 0.035]。
   - **SYSU**：只用图像不如元数据，测试上是 0.099 对 0.116。
     - 把图像和元数据两个分支各自训练好再做晚融合（α=0.5），② AP 在测试上是 0.151，验证上是 0.120。
     - 融合减元数据重训的差为 +0.035 [0.021, 0.050]，3 个种子都为正。
2. **图像加元数据：直接拼接没有用，晚融合有用。**
   - 拼接训练与只用图像几乎相同，SECOND 测试上是 0.129 对 0.129。
   - 晚融合在测试上的增益：
     - SECOND：比图像高 0.009 [0.007, 0.011]；
     - SYSU：比元数据高 0.035。
3. **按“每图前 k 个”计预算时，SECOND 上图像判断器反而不如元数据。**
   - SECOND 测试，前 10 个的 ② 对象召回：

     | 方法 | 召回 |
     |---|---:|
     | 元数据重训 | 0.181 |
     | M1-ign3 | 0.164 |
     | 融合 | 0.156 |
     | 图像 | 0.137 |
     | oracle | 0.297 |

   - SYSU 测试，前 3 个的 ② 对象召回：

     | 方法 | 召回 |
     |---|---:|
     | 融合 | 0.344 |
     | 元数据重训 | 0.332 |
     | M1-ign3 | 0.325 |
     | oracle | 0.408 |

   - 原因：图像判断器把每图前几名的位置让给了“像变化”的大块，这些大块在单元个数上不占优，在像素误检上却更省。
4. **按 F1 代价计时，图像信息在 SECOND 上更划算。**
   - 测试上，同样的 ΔF1 下，图像和融合能补到更多 ②，见图 `frozen_points_test.png`。
   - 在 ΔF1 约 −6.5 处比较：

     | 方法 | ② 对象召回 |
     |---|---:|
     | 融合 | 0.363 |
     | D | 0.325 |
     | 元数据重训 | 约 0.31 |

   - 但 SECOND 测试与验证之间有明显漂移：验证上冻结在 ΔF1 ≥ −1 的阈值，在测试上的 ΔF1 实际是 −3.5 到 −8.3。连 D 也一样，所以是数据漂移，不是判断器的问题。
5. **在 exp6j 抽的同一批单元上，判断器明显好于遥感 MLLM 零样本。**

   | 数据集 | 本实验判断器 ② AUC | 最好的 MLLM ② AUC |
   |---|---:|---:|
   | SECOND | 0.695 | 0.572 |
   | SYSU | 0.664–0.671 | 0.556 |

6. **验证错误样例里，判断器的错大多是把伪变化判成变化。**
   - 主要类型：同一地物外观变化、光照或阴影、色调差异、碎片小块。
   - “判断器对、D 错”的 24 例里，23 例是伪变化被正确压低。

## 数据与对照

- **数据**：U5_x4 单元，按 1d 冻结规则分到补漏组，再套 exp8s6 冻结过滤（SECOND F3A200，SYSU F2）。判断对象是过滤后的新增像素。
- **标签**：新增像素的真值占比 ≥ 0.5 为正，< 0.1 为负。
- **ign3**：训练时忽略 ③ 为主的正例，沿用 exp8s3。理由是 ③ 的新增像素有检测器信号，不是补漏组要学的东西，混进来会把判断器推向“检测器高分”。
- **对照**：

| 代号 | 内容 |
|---|---|
| D | 单元内检测器均值，不训练 |
| M1-ign3 | exp8s3 已训练的元数据判断器，直接打分 |
| 元数据重训 `meta-m1` | 与 M1-ign3 结构相同，在过滤后的数据上重训 |
| 图像 `img` | 冻结 DINOv3 特征 + MLP，下文第 1 轮 |
| 图像+元数据拼接 `img-meta` | 拼接后训练 |
| 晚融合 `fuse` | 两个分支各自训练后再组合分数，下文第 2 轮 |
| oracle | 按新增像素的真实精度排序 |

- 学习类方法都用种子 1020、1021、1022，表中的值是 3 个种子指标的平均（不是分数集成）。正式评分器预先指定为种子 1020。

## 迭代记录

### 第 0 轮：动手前的方法检索

**问题**：请 Codex 查知识库，看小区域双时相判断、伪变化、遥感骨干分别有哪些做法。

**Codex 的建议**：
- 卫星预训练的 DINOv3 SAT-493M；
- 对称的两期特征；
- 小的头部网络；
- 1:3 采样；
- 先定好成功标准。

**我的取舍**：
- 第 1 轮先用整图前向加掩码池化。这样每张图只前向一次，比 Codex 建议的按候选裁 256 小块便宜得多。
- 对称特征和小头留到第 2 轮做对照。

### 第 1 轮：冻结 DINOv3 + 掩码池化 + MLP

- **假设**：过滤后的补漏单元足够大，冻结的遥感特征加上两期差异，就能区分真实变化和伪变化。
- **做法**：
  - DINOv3 ViT-L/16 SAT-493M 冻结，每张图对两期各前向一次，输入尺寸为 SECOND 512→1024、SYSU 256→768。
  - 在新增掩码内，对第 12 层和最后一层的 token 做均值池化；另取掩码外一圈环形区域的最后一层均值。T1、T2 各一份，每个单元共 6×1024 维。
  - 头部输入 `[f1, f2, f2−f1, |f2−f1|]`，经 LayerNorm 后接 2 层 MLP（隐层 512，dropout 0.2）。损失用加权 BCE，按验证 ② AP 早停。
  - 特征提取共 1.8 GPU 小时。
- **结果**（验证，② AP，3 个种子平均）：

| | D | M1-ign3 | 元数据重训 | 图像 | 图像+元数据 | 图像+元数据（无环形） |
|---|---:|---:|---:|---:|---:|---:|
| SECOND | 0.089 | 0.108 | 0.116 | **0.206** | 0.195 | 0.194 |
| SYSU | 0.062 | 0.087 | **0.092** | 0.088 | 0.094 | 0.090 |

- **判断**：
  - SECOND 上图像信息有效，AUC 从 0.69 提到 0.78。
  - SYSU 上图像没有超过元数据，“全部正例”的 AUC 只有 0.61。
  - 拼接训练没有超过两者中较好的一个。

### 第 2 轮：Codex 评审后的三个对照和晚融合

Codex 评审第 1 轮后提出了三个方向，并预先写好了采用标准。

**采用标准**（3 个种子平均，并做按图配对的自助法）：
- ② AP 比最强参照高：SECOND 至少 0.010，SYSU 至少 0.005。参照是 SECOND 的 `img`、SYSU 的 `meta-m1`。
- 差值置信区间的下界大于 0，且至少 2 个种子为正增益。
- 低预算召回提高：SECOND 看前 10 个，至少高 0.010；SYSU 看前 3 个，至少高 0.020。
- ΔF1 ≥ −1 冻结点上的召回不能下降超过 0.010。

**三个方向**：
- **E1**：对称特征 `(f1+f2)/2`、`|f2−f1|` 加小头，参数从 658 万降到约 18 万。
- **E2**：在 E1 上改为 1:3 采样，用普通 BCE。
- **E3**：只做 SYSU。按候选从原图裁出局部小块，裁块边长为 L=min(256, max(64, 2b))，b 为 bbox 最长边，缩放到 512 输入后重新提特征。

**晚融合**：分数先取 logit，再用训练候选的均值和方差标准化，然后计算 `α·z_img + (1−α)·z_meta`，α 取 0、0.25、0.5、0.75、1。两个数据集各选一个 α，3 个种子共用。

**结果**（验证，② AP，3 个种子平均）：

| | E1 | E2 | E3 | 融合（最佳 α） |
|---|---:|---:|---:|---:|
| SECOND | 0.163 | 0.156 | — | 0.206（α=0.75） |
| SYSU | 0.061 | 0.059 | 0.058 | **0.120**（α=0.5） |

**判定**（Codex 按标准逐条判，我同意）：
- E1、E2、E3 都明显变差，不采用。
  - 只能说明这组设计在少正例的情况下变差，不能说明对称性或局部视野本身无用。
  - E3 的特征提取实测只花了约 0.8 GPU 小时。
- **SECOND 融合（α=0.75）：证据不足。**
  - AP 和图像持平：+0.0003 [−0.010, 0.011]。
  - 前 10 个的召回高 0.009 [0.003, 0.016]，没达到 0.010 的门槛。
- **SYSU 融合（α=0.5）：排序改善了，但补漏收益不足。**
  - AP 高 0.028 [0.004, 0.057]，3 个种子都为正。
  - ΔF1 ≥ −1 冻结点上的召回高 0.038 [0.004, 0.074]。
  - 前 3 个的召回只高 0.006，没达到 0.020 的门槛，平均只多补到 1 个对象。

**冻结方案**：
- **正式评分器**：没有一个新配置通过全部标准，所以保留第 1 轮的强参照，即 SECOND 用 `img-s1020`，SYSU 用 `meta-m1-s1020`。
- **固定对照**：两份融合预先指定为一起上测试的对照，即 SECOND 用 α=0.75，SYSU 用 α=0.5。
- **不做第 3 轮**：Codex 估计 LoRA 微调末几块在两个数据集上合计要 43–83 GPU 小时，也没有证据表明能过门槛。剩下的预算不用于继续搜索。

**配对差**（测试，3 个种子平均，按图自助法 95% 置信区间）：

|---|---|---:|

辅助指标（测试，3 个种子平均）：
- **全部正例 vs 负例 AP**：

  | | D | 元数据 | 图像 | 融合 |
  |---|---:|---:|---:|---:|
  | SECOND | 0.254 | 0.215 | 0.252 | 0.274 |
  | SYSU | 0.338 | 0.279 | 0.188 | 0.295 |

  SYSU 上，D 在“全部正例”上仍是最好的，因为 ③ 正例有检测器信号。
- **② 正例 vs 难负例 AUC**（难负例 = D 最高的 20% 负例）：D 只有 0.19（SECOND）和 0.31（SYSU），元数据重训 0.41 / 0.47，图像 0.55 / 0.63，说明图像能压低检测器的高分误报。

**验证到测试的漂移**：SECOND 的图像 AP 从 0.206 降到 0.129，而 D 和元数据几乎不变（0.089→0.087，0.116→0.102）。
- 原因可能是 SECOND 的训练和验证都来自官方训练集的交叉拟合，检测器和影像分布一致；测试用的是官方检测器加官方测试集。
- 图像头在训练和验证同源的情况下早停，对测试分布有过拟合。
- 这个下降不影响“图像好于元数据”的结论，配对区间不跨 0。

## 错误样例（验证，12 + 12 每数据集）

**目录**：`results/exp8s7_error_examples/{second,sysu}/`，每个目录里有 JPEG、`index.html`、`annotations.csv`。

**每张图的四格**：T1 近景、T2 近景（红色轮廓是新增像素）、T2 上下文、检测器热力图。

**抽样与阈值**：
- 两个判断器：SECOND 用冻结的 `img-s1020`；SYSU 用 `fuse-img-a0.5-s1020`，因为这是带图像信息的最好方案。
- 判断器和 D 的阈值各自在验证上按“加权二分类 F1 最大”选取。
- 从每个方向中随机抽 12 个。
- 补漏组里负例占约 95%，所以抽到的几乎都是负例。

**分类**：由 Codex 逐张看图完成。下表的类别按文档要求合并：季节或物候、色调或成像差异合为“季节或色调”；同一地物外观变化、光照或阴影计入“其他”。

| 判断器错、D 对 | SECOND | SYSU |
|---|---:|---:|
| 季节或色调 | 3 | 1 |
| 认错地物 | 1 | 0 |
| 配准错位 | 1 | 2 |
| 真值可疑 | 0 | 1 |
| 太小看不清（碎片） | 2 | 3 |
| 其他：同一地物外观变化 | 3 | 1 |
| 其他：光照或阴影 | 2 | 4 |

- **“判断器对、D 错”**：SECOND 12 个、SYSU 11 个都是伪变化被正确压低，例如阴影、屋顶遮阴、建筑边缘投影、绿化偏色。剩下 1 个 SYSU 样例看不清依据。
- **“判断器错、D 对”**：除 SECOND 的 2 个正例被漏掉外，都是误报。主要是把同一地物的换色、阴影、碎片当成了变化。
- **真值可疑**：SYSU `train_15779.png` 单元 2 疑似植被被清除，但真值标的是无变化。

## 判断问题

1. **图像信息能否明显超过元数据？**
   - SECOND：能。测试 ② AP 从 0.102 提到 0.129，融合 0.138，但没到 0.15；验证上是 0.206。
   - SYSU：只用图像不能。要和元数据做晚融合，测试才到 0.151。
2. **图像 + 元数据比单独好多少？**
   - 拼接训练没有好处。
   - 晚融合在 SECOND 上比图像高 0.009 AP，在 SYSU 上比元数据高 0.035 AP，置信区间都在 0 以上。
3. **每图前 10 / 20 个能盖住多少 ②？**
   - SECOND 测试：融合 0.149 / 0.251，图像 0.132 / 0.230。
     - 比 M1-ign3（0.164 / 0.270）低约 0.02–0.04。
     - 比 oracle（0.297 / 0.437）低约 0.15–0.19。
   - SYSU 测试，前 3 / 20 个：融合 0.340 / 0.528。
     - 比 M1-ign3（0.325 / 0.524）略高。
     - 比 oracle（0.408 / 0.551）低 0.07 / 0.02。
   - 按单元个数计预算时，元数据在 SECOND 上更好；按 F1 代价计时，图像更好（见冻结点一节）。
4. **和 exp6j 最好的遥感 MLLM 零样本相比如何？** 在同一批单元上，② AUC 在 SECOND 上是 0.695 对 0.572，在 SYSU 上是 0.671 对 0.556。冻结 DINOv3 加一个小头已经明显好于 MLLM 零样本。
5. **主要错在哪？下一步做什么？**
   - **主要错误**：同一地物外观变化、阴影、色调这几类伪变化，以及碎片小块。
   - **下一步建议**：
     - 在合并方案里，用图像判断器或融合分数给 MLLM 排待查清单，配合 exp6k 的 ICL 示例。示例里专门放这几类伪变化，让 MLLM 去复核排在前面的候选。
     - SECOND 的验证到测试漂移需要单独处理：阈值改按“每图预算”而不是“ΔF1 阈值”冻结，或者用测试同源的检测器重做验证划分。
     - 不建议继续加大模型：第 2 轮的三个改动都变差了。
