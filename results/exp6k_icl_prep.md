# 实验 6k（准备）：MLLM 上下文示例的示例池、开发集与测试样本

日期：2026-10-27。任务原文：`doc/exp6k_icl_demo_prep.md`。本轮只做准备：没有跑 MLLM，没有训练，全部计算是 Slurm 上的 1 CPU 作业。

## 结论

1. 两个数据集的变化口径和系统提示草稿（中英文各一版）已写好，并登记进审核前端库，共 4 个提示词版本。
2. 每个数据集有三类样本：
   - 示例池 64 个和扩展池 256 个，都取自训练部分，正负各半；
   - 开发集 600 个，取自验证部分；
   - 测试样本 1,500 个，取自测试部分。
   三者按原图互不重叠。
3. 示例池的正例理由由程序生成。核心池负例由 Codex 逐张看图，标伪变化类型和理由，共 96 个候选，其中 2 个标为真值可疑并已剔除。
4. 文档里有两处口径与原论文不一致，已按原论文改写提示：
   - SECOND 的二值变化**不等于**“两期类别不同”：同类内部的真实变化（如建筑拆除重建）也标为变化；
   - SECOND 的第 6 类是**运动场**，不是“不透水面”：不透水面属于“非植被地表”。
5. 审核前端已在服务器上启动，可以审核。

## 候选与标签

- 候选都是 exp8 的 U5_x4 单元，先按 1d 冻结规则（单元自身 r < 0.1）分到补漏组，再套 exp8s6 冻结过滤：
  - SECOND：去细条，新增像素 ≥ 200；
  - SYSU：开运算，新增像素 ≥ 100。
  这一步直接复用 exp8s7 已建好的单元表。
- 判断对象是过滤后的新增像素。新增像素的真值占比 ≥ 0.5 为“有变化”，< 0.1 为“无变化”，介于两者之间的不用。
- 每个候选记录以下字段：
  - 面积和面积档：< 300、300–1000、1000–3000、≥ 3000；
  - 来源，取值为 B、G0.05、H1 或它们的组合；
  - 检测器均值 D 和 M1-ign3 分数；
  - 主格：① ② ③ ⑤；
  - 新增掩码内两期的 RGB 平均差；
  - SECOND 另记新增掩码内两期的语义主类。

## 第 1 部分：变化口径与系统提示

口径由 Codex 查遥感知识库整理，原文和出处编号见服务器 `batch49/consult/ANSWER_defs.md`。

**SYSU-CD**（出处：Shi et al. 2021 TGRS（DSAMNet）§I、§III；作者 GitHub 数据集说明）：
- 影像：香港航空影像，0.5 米分辨率，2007–2014 年，256×256 图块。
- 标注：二值掩码。主要变化类型有城市新建建筑、郊区扩张、建设前的场地准备、植被变化、道路扩建、海上建设。
- 伪变化：论文只说光照、阴影和偏移是干扰因素。没有找到关于季节、屋顶换色、车辆的逐项排除条款，这几条是推断。

**SECOND**（出处：Yang et al. arXiv:2010.05687 §II-C、§III、§IV；SECOND 项目页）：
- 类别：6 类，即低矮植被、非植被地表（含不透水面和裸地）、树木、水体、建筑、运动场。
- 二值变化：用独立的二值掩码标注，同类内部的真实变化也算变化。
- 语义：语义图只在变化区域给地类，无变化区为背景 0。
- 伪变化：没有找到官方的逐项排除条款，各条判断要点是推断。

**伪变化类型**：季节或物候、光照或阴影、色调或成像差异、同一地物外观变化（屋顶换色或翻新）、临时物体（车辆等）、配准错位。
- 判断要点由 Cheng et al. 2024（Remote Sensing 16(13):2355 §1、§2.1）、Lebedev et al. 2018 §3 和 exp6j 的判错分析归纳而来。
- 对这两个数据集的具体应用属于推断，提示词的备注里写明了这一点。

**提示词**：`second_sys_v1_zh/en`、`sysu_sys_v1_zh/en`，原文在 `code/probe/exp6k_prompts/`，出处在 `notes.json`，同时作为备注写进库。结构如下：
1. 说明数据集标注的“变化”是什么；
2. 逐条列出伪变化，并说明“一律判无变化”；
3. 只判断红色轮廓内的新增像素；
4. 回答“是 / 否”加一句理由。

与原文档的差异：
- 正例理由用“t1 类 → t2 类”。若两期是同一类，加注“同类内部变化，如拆除重建”，不判成无变化。
- 第 6 类改为“运动场”。

## 第 2 部分：示例池（训练部分，种子 20261027）

**正例**（每个数据集 32 个），由程序挑选，不看图：
- 筛选条件是真值占比 ≥ 0.7 且面积 ≥ 150，用来避开真值可疑和太小的单元。这两个阈值是我定的。
- 构成：② 为主 24 个，① 为主 8 个。
- 按面积档、来源，以及 SECOND 的变化种类轮流取，尽量均衡。
- 理由：SECOND 写“t1 类 → t2 类”；SYSU 写“有变化，面积档 X”。

**负例**：
- 先抽 48 个候选，其中难负例 36 个。难负例指检测器均值或两期 RGB 差位于该划分负例的前 20%。
- 由 Codex 逐张看 T1/T2 近景和整图缩略图，疑点另看整图和真值掩码，然后填伪变化类型、理由，以及是否真值可疑。
- 程序先排除真值可疑的，再按伪变化类型轮流选出 32 个，其中难负例 ≥ 16。
- 同一张图最多取 2 个示例。

| | SECOND | SYSU |
|---|---:|---:|
| 示例池（正 / 负） | 32 / 32 | 32 / 32 |
| 正例主格 ② / ① | 24 / 8 | 24 / 8 |
| 负例中难负例 | 24 | 28 |
| 涉及图数 | 64 | 61 |
| 面积档（< 300 / 300–1000 / 1000–3000 / ≥ 3000） | 17 / 16 / 16 / 15 | 16 / 16 / 16 / 16 |

**看图标注的伪变化类型**（48 个负例候选，Codex 标注）：

| 类型 | SECOND 候选 | SECOND 入池 | SYSU 候选 | SYSU 入池 |
|---|---:|---:|---:|---:|

**真值可疑**：两个数据集各 1 个，已剔除。
- SECOND `train_1841:46`：后期出现成排矩形构件，疑似建设漏标。
- SYSU `train_15193:62`：绿化消失，并与施工裸地连通，疑似场地准备漏标。

“类型不明”的负例（每个数据集 5 个）仍留在池里，理由写的是看到了什么、为什么判断不了。审核时如果觉得不适合当示例，可以直接剔除。

**SECOND 正例的变化种类**：32 个分布在 26 种 t1 → t2 组合上，每种 1–2 个。其中“建筑 → 建筑”（同类内部变化）1 个，含运动场的 5 个。

**256 扩展池**：
- 由 64 个的核心池，加上 96 正、96 负的扩展候选组成，扩展候选的挑选规则与核心池相同。
- 扩展部分的负例理由统一写“无变化”，不标伪变化类型；正例理由同样由程序生成。
- 扩展部分标了 `rationale_source=auto`。
- 涉及图数：SECOND 242，SYSU 227。

**渲染**：

| 形式 | 内容 |
|---|---|
| A | T1、T2 近景，各 384 px，两期都用红色轮廓画出新增像素 |
| B | 整图 T1、T2（红框标出候选位置），整图二值变化真值；SECOND 另附两期语义图和语义文字说明 |
| 缩略图 | 整图位置缩略图 |

- A 形式直接调用 exp6j 的裁剪和描边函数，与零样本评测的输入逐像素一致。裁剪边长为 bbox 最长边的 4 倍，最小 64 px。

## 第 3 部分：开发集与测试样本

**分层**（与审核前端的指标口径一致）：
- `pos2`：② 为主的正例；
- `pos_other`：其他正例；
- `hard_neg`：检测器均值位于该划分补漏负例前 20% 的负例；
- `rand_neg`：其余负例。

**抽样**：开发集每层 150 个，测试样本每层 375 个，种子 20261027。权重为“该层总数 ÷ 抽取数”。

| | SECOND 开发 | SECOND 测试 | SYSU 开发 | SYSU 测试 |
|---|---:|---:|---:|---:|
| 样本数 | 600 | 1,500 | 600 | 1,500 |
| 图数 | 231 | 908 | 311 | 971 |
| 权重 pos2 / pos_other / hard_neg / rand_neg | 8.3 / 10.1 / 27.7 / 110.9 | 20.4 / 21.3 / 72.0 / 287.8 | 1.7 / 4.9 / 13.6 / 54.5 | 3.1 / 7.4 / 22.5 / 90.0 |

**输入**：
- 查询只给 A 形式，外加不含真值的整图 T1/T2（红框标出候选位置）。
- 不给真值掩码和语义，SECOND 查询的 `change_kind` 和 `semantic_text` 留空。

**按图清单**：每张图记录被抽中的候选和该图补漏组候选总数，存在 `exp6k_{dev,test}_<ds>_images.json`，批量提问时用。

## 与 Codex 的讨论

1. **口径查证**（ASK_defs / ANSWER_defs）：Codex 从知识库读了 SECOND 原论文 PDF，并核对了 SYSU-CD 论文和作者说明，指出了文档的两处偏差：
   - SECOND 的二值变化不等于两期类别不同，同类内部变化也算；
   - 第 6 类是运动场。

   它还提醒：
   - SYSU-CD 没有官方的伪变化逐项条款，提示里相关说法要标成推断；
   - “海上建设”是正例，不能因为位于水面就判无变化。

   这些都已采纳。
2. **负例看图标注**（ASK_label / ANSWER_label）：按文档要求交给 Codex 做，我只检查格式和计数。

   Codex 共看了 288 张近景和缩略图，另看了 36 张整图和掩码。

   它提出了现有单选类型表达不了的情况：
   - 高楼视差和遮挡同时出现（暂归入“配准错位”）；
   - 候选混了多种地物，或被图像边缘截断；
   - 植被遮蔽与路径废弃分不清；
   - 堆放物与地表改造可能同时存在。

   本轮没有新增类型，这些情况写在理由里。
