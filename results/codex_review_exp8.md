## 5. 文献补充

- **SECOND原论文允许同类真实变化，但没有给出“屋顶换色／落叶转绿”的明确判例规则（非仓库依据）** → Yang等《Semantic Change Detection with Asymmetric Siamese Networks》，[§IV SECOND](https://arxiv.org/html/2010.05687#S4)明确指出仅比较地类图会漏掉建筑拆除重建，并用独立变化掩码区分同类变化与未变化；所核实正文未明确规定纯屋顶颜色变化和季节物候变化 → 可以确认“同类变化允许存在”，不能确认“纯换色应算变化”或“所有同类变化都是噪声”。
- **排除季节性外观变化有明确的数据集先例（非仓库依据）** → Lebedev等，ISPRS 2018，[《Change Detection in Remote Sensing Images Using Conditional Adversarial Networks》§3，印刷第566页](https://isprs-archives.copernicus.org/articles/XLII-2/565/2018/isprs-archives-XLII-2-565-2018.pdf)，明确以对象出现／消失为变化，排除季节和亮度差异，并采用pix2pix式条件GAN → 可作为另设“真实事件审核口径”的出处，不能自动覆盖SECOND官方任务定义。
- **LEVIR的任务定义也将季节和光照差异作为干扰（非仓库依据）** → [LEVIR作者项目页](https://justchenhao.github.io/LEVIR/)定义建筑增长／减少，并说明特意引入季节、光照差异以研究抑制无关变化 → 四数据集审核应分别列出官方目标事件；不能用LEVIR的建筑增减规则直接裁决SECOND的改建标签。
- **语义一致性约束是已发表的方法，但不能解决任务定义分歧（非仓库依据）** → Ding等《Bi-Temporal Semantic Reasoning…》，[§III-D](https://arxiv.org/html/2108.06103#S3.SS4)用变化标签约束两期语义预测的一致性；本仓库6h已测试两种相关特征约束且未获稳定收益 → 文献中可列作方法依据；不能宣称加一致性损失就能修正争议标签，也不能把6h结果外推成所有季节性抑制方法无效。
